## 一、核心玩法循環（Core Gameplay Loop）

本作採用**固定斜俯正交視角（Fixed Isometric-Orthographic Camera）**呈現手繪繪本微縮感，操作保持輕量化（約 5–6 個核心按鍵），主打流暢的無縫上下騎（Mount / Dismount）、人獸體型差開路、節奏破防合擊與雙軌刷裝循環：

1. **探索開路（體型差協作 Traversal）**：騎乘巨型動物夥伴高速跑圖、撞破木障、硬扛沙暴或飛躍峽谷；遇上窄縫、樹洞、搖晃獨木橋或精密機關時一鍵下鞍，由小旅人鑽入開閘或拆陷阱，再吹哨讓巨獸會合。
2. **合力戰鬥（破防處決 Stagger & Counter）**：舊時代老 Boss 具備厚重護甲與蓄力大招。玩家指揮巨獸肩撞、舉盾或咆哮打斷蓄力，製造**踉蹌破綻（Stagger）**，再由小旅人近身爆發或遠程射擊弱點扣環，最後讓胖黃羽信使鳥俯衝蓋下「正式退休」紅章完成處決。
3. **回城改裝（刷裝與配裝 Build Loop）**：擊敗 Boss 掉落「百年封存舊軍品」與「鞍具零件」，返回雲丘主城於骨盔哥布林處交易，並於沙暴騎士長的改裝工坊洗鍊詞綴，持續強化旅人與巨獸雙軌戰力。

## 二、角色與「武器定職業」系統（Weapon-Defined Classes）

為配合輕鬆探索節奏與刷裝自由度，本作不鎖死創角職業，改採**「裝備主武器即決定職業定位」**設計，玩家可隨時換裝切換玩法。初版聚焦四大基礎路線：

| 職業路線 | 主武器與視覺 | 戰鬥定位 | 與巨型動物夥伴之配合亮點 |
| :--- | :--- | :--- | :--- |
| **前線反擊手** | 短劍＋圓盾 | 近戰高爆發、舉盾格擋反擊 | 巨獸撞斷 Boss 蓄力後，旅人立刻下騎貼身連斬，打擊感最直接 |
| **弱點狙擊手** | 彈弓／輕弓 | 中遠程點射、專破 Boss 弱點扣環 | 可直接**坐於巨獸背上邊移動邊射擊**，主打風箏走位與高頻破甲 |
| **戰術爆破手** | 舊軍品扳手＋機關包 | 設置陷阱、煙霧彈與定時炸彈 | 旅人布設地雷或黏附炸彈後，指揮巨獸將 Boss 撞入雷區引爆 |
| **旅途支援師** | 營火提燈＋湯勺法杖 | 範圍治療、護盾、設置隨身小營火 | 團隊副本核心輔助；巨獸聚怪扛傷，旅人以營火同時灼燒敵人並治療隊友 |

**第三常駐角色「胖黃羽信使鳥」**：不增加操作鍵位負擔，自動負責拾取金幣、遇隱藏寶箱時於帽頂拍翼提示，並在 Boss 進入破防時主動飛撲蓋章，提供額外傷害或掉寶率（Loot Bonus）加成。

## 三、巨型動物夥伴系統（Retired Beast Guide Roster）

開局預設領取最具代表性的**退休斥候巨狼**；為強化 MMORPG 的角色辨識度與組隊分工，隨主線推進可於勸退公會解鎖並切換更多**領有導遊執照的退休巨獸**：

| 巨型動物夥伴 | 退休前身分與定位 | 專屬體型差開路特技 | 戰鬥合擊特色 |
| :--- | :--- | :--- | :--- |
| **退休斥候巨狼**（看板起點） | 前魔王軍精銳斥候／全能突擊型 | 撞碎枯木路障、蓄力飛躍峽谷 | 高速肩撞打斷蓄力、咬住目標降防；眼神冷靜酷帥，夜晚營火旁會蜷身護住主角 |
| **退休重甲巨熊** | 前魔王軍攻城兵／重裝坦克型 | 撞碎紅岩巨石、高舉拋投旅人上高台 | 展開正面巨盾替全隊硬吃 Boss 全屏大招，適合多人副本主坦 |
| **退休雲海巨鹿** | 前夜間行軍照明隊／元素支援型 | 驅散高空迷霧、踏風加速衝刺 | 展開大範圍移速與元素共鳴光環，極適合配搭遠程或支援流派 |
| **退休沙暴大穿山甲** | 前地下工兵／重工碾壓型 | 鑽開流沙丘與地下密道捷徑 | 縮成巨球高速滾翻碾壓小怪群，清場效率極高 |

每隻巨獸皆具備獨立的非語言互動演出（於營火旁打盹、瀑布洗毛甩水、更換新鞍具時低頭端詳），強化拍檔溫度而非純粹加速坐騎。

## 四、雙軌裝備系統（Traveler × Beast Dual-Track Gear）

所有主要裝備穿戴後皆即時反映於角色與巨獸外觀，創造雙倍刷裝回饋感：

### 旅人裝備（5 格）
1. **主武器**：決定基礎職業技能組。
2. **副手**：圓盾、箭袋、冒險筆記本或四葉草幸運符（提供功能型被動）。
3. **羽毛帽**：外觀辨識度最高，主加核心屬性與套裝效果。
4. **旅人衣靴**：影響移動速度、閃避無敵幀與體力回復。
5. **隨身水壺（可刷詞綴藥水）**：飲用除回復生命外，亦可觸發限時增益詞綴（例如：飲用後 5 秒內下一次人獸合擊必出暴擊）。

### 巨獸裝備（4 格，直接掛載於獸背與四肢）
1. **戰術鞍座（Build 核心）**：改變上下騎操作手感與觸發效果（如《彈簧試驗鞍座》、《重裝炮台鞍》）。
2. **護爪／護角**：強化衝撞破防效率與元素附魔（火、冰、雷、毒菇）。
3. **獸背護甲**：影響巨獸生命、減傷、嘲諷範圍或衝鋒反傷。
4. **鞍側掛飾**：掛於鞍邊的營火茶壺、哥布林鈴鐺或骨飾，加成掉寶率、營火 Buff 或黃鳥蓋章威力。

## 五、配裝構築系統（Build Crafting & Synergies）

捨棄過度龐雜的天賦樹，改採直覺清晰的**「旅人 × 巨獸 × 鞍座」三層觸發詞綴連動（Synergy Tags：破防、下騎、營火、灼燒、蓋章）**，讓玩家從前期即能體驗改變手感的流派構築：

### 代表性流派範例
- **「彈射飛天斬」流（短劍＋斥候巨狼＋彈簧試驗鞍座）**：巨狼肩撞觸發破防 → 按 `F` 觸發彈射鞍座騰空 → 空中下劈吃滿「下騎 3 秒內暴擊傷害翻倍」詞綴 → 落地翻滾重新上鞍重置冷卻。
- **「移動營火燒烤」流（營火提燈＋重甲巨熊＋鞍側茶壺）**：巨熊嘲諷聚怪扛傷 → 旅人投擲「隨身營火」持續灼燒 → 鞍側茶壺每次觸發灼燒傷害即為全隊回血與加速。
- **「百倍蓋章暴富」流（彈弓＋雲海巨鹿＋郵政官帽）**：騎乘高速繞圈點射 Boss 弱點，每次破點觸發帽飾特效，召喚胖黃鳥化作金色殘影連續蓋下 3 次「退休紅章」，疊滿印記引爆真實傷害並大幅提升掉寶率。

### 低挫折魔改機制（沙暴騎士長工坊）
- **詞綴鎖定重洗**：刷得優質底材後，可鎖定一條核心詞綴重洗其餘條目。
- **傳奇特效萃取轉移**：淘汰裝備上的獨特鞍座或武器特效可拆解並轉印至新裝備，兼顧刷寶驚喜與長線育成平滑度。
