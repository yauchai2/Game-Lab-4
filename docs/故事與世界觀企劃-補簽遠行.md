## 一、世界觀背景：大和平之後的荒誕現狀

一百年前，這片繽紛的奇幻大陸曾爆發過一場名義上轟轟烈烈的「百年魔人戰爭」。然而這場大戰的結局極其草率——在最終決戰前夕，魔王軍與王國聯軍同時遭遇斷糧危機，加上雙方領袖皆已疲憊不堪，兩邊索性在戰場營火旁一邊烤魚、一邊簽署了《全面停戰與魔物轉職協議》。

和平時代迅速展開。曾經令世人畏懼的魔物們紛紛轉行投入民生產業：哥布林開起清倉兵器舖、亡靈將陰森骷髏洞改造成河畔露營區、巨狼族考取了「跨地形導遊與保鑣執照」。

**故事的荒謬導火線**：當年負責派送停戰通知書的，是一群可愛、忠誠但極度路癡又怕熱的「黃羽信使鳥」。城鎮與大道沿線的魔物都順利收到通知並開心轉行；唯獨駐守在深林、瀑布底、紅岩荒漠與雲海山巔的**舊時代大 Boss 們**，足足一百年都沒收到半張公文，至今仍在崗位上認真擦拭武器、背誦台詞、苦等勇者前來決戰，順便霸佔了大陸最美的觀光景點與百年封存的頂級軍品庫。

為解決這批「歷史遺留問題」，人類與退休魔物聯合成立了**「大和平旅務局（簡稱：勸退公會）」**。全大陸的年輕旅人背起小書包、領取持牌巨狼拍檔，踏上**「強制派信、協助退休、順便回收古董神裝」**的大冒險。

## 三、魔物退休後的城鎮與社會生態

- **雲丘主城（新手起點與社交樞紐）**：座落於粉紫雲海之上的白色尖頂小屋群，聚集著勸退公會總部、交易行與各類退休魔物商舖。
- **骨盔哥布林特價兵器行**：由前魔王軍軍需官經營，頭戴帶角白骨頭盔、滿面笑容地在櫃檯推銷清倉舊軍品，店內貼滿 `-50¢` 折扣標籤，玻璃櫃裡擺著當年的骷髏王冠與魔法戒指當文創紀念品販售。
- **骷髏洞河畔露營區**：昔日陰森的亡靈前線要塞，洞口是長滿青苔的巨大骷髏石雕；如今由退休亡靈經營成河畔熱門營地，提供免費柴火、巨狼梳毛服務與夜間熱飲。
- **石魔像基建隊與史萊姆清潔社**：負責將舊戰場改建為觀光步道與溫泉旅社。每當玩家勸退某區的老 Boss，他們便會進駐該地圖，讓場景實際新增捷徑、商店與營火據點。

## 四、遊戲全流程規劃（從開局到結局）

### Phase 0：進入遊戲與序章《遲到一百年的派信日》（0–30 分鐘）
1. **標題畫面與創角**：深藍夜色中的溫暖營火場景，巨狼捲身打盹。玩家同時自訂小旅人（帽飾、新手武器）與巨狼拍檔（毛色、耳型、眼神神態）。
2. **開場 60 秒極反轉**：先以莊嚴史詩旁白鋪陳百年大戰，鏡頭隨即切入陽光熱鬧的雲丘主城，迅速揭曉魔物全面轉行的現況。
3. **骨盔哥布林武器行**：以 `-50¢` 清倉價購入第一把閃亮短劍，建立輕鬆幽默的對話基調。
4. **公會報到與領狼**：加入勸退公會，與冷靜的巨狼拍檔及胖黃鳥正式成隊。
5. **新手教學 Boss — 過度敬業的稻草人哨長（雲海橙丘）**：
   - 死守新手村外石橋、執著背誦百年前盤查口令。
   - 教學完整閉環：騎狼撞開木障 → 下鞍鑽草叢切斷背後發條 → 合力破甲獲得第一批裝備 → 黃鳥蓋下第一個退休章。
   - 哨長退休後搬至雲丘鎮口擔任觀光指引員，同步解鎖**野外營火系統**。

| **第一章：翡翠天梯古林** | 翠綠巨葉長階梯；入夜轉為螢光深藍森林與骷髏洞營地 | **失聰的苔蘚樹王守衛**：將排隊喝蘑菇湯的遊客誤認為敵軍包圍網，用藤蔓封死秘境階梯 | 巨狼「破木衝鋒」撞開枯木壁；旅人「鑽縫解鎖」解除樹根機關。解鎖**多人營火社交與料理 Buff** | 將地宮改建為「樹屋夜光茶館」，販售高階夜間增益湯品 |

| **第三章：赤岩堡壘荒漠** | 炙熱紅岩巨拱、仙人掌、沙中白骨與遠方高聳砂岩堡壘 | **每天獨自早操的沙暴騎士長**：對著一排仙人掌喊立正稍息，堅信援軍明日即至（此區黃鳥會熱暈攤平在石頭上） | 巨狼「沙暴突進」撞碎岩拱捷徑；旅人潛入高塔通風口拆除百年烽火台。解鎖**舊軍品詞綴魔改與套裝共鳴** | 進駐雲丘主城開設「舊軍品改裝工坊」，並首次揭露「最高機密未寄出信件」伏筆 |

### Phase 5：最終章與主線結局《最後一張退休章》
- **最終場景（靜默營火谷）**：百年前雙方簽約的起點山谷，四周靜謐如時間停駐。
- **情感反轉與真相**：最後一封信的收件人是巨狼百年前效忠的**前代魔王／傳說老隊長**。牠其實早就知曉停戰，卻擔心和平只是短暫幻象、人類仍會恐懼魔物，於是獨自留在舊戰場守候百年，將所有舊時代的包袱留在自己身上。
- **最終戰（盛大的告別演習）**：老隊長一眼認出玩家的巨狼，欣慰地提出以一場沒有惡意的切磋檢驗新世界的旅人。戰鬥融合全套騎狼突進、下鞍拆機關與人狼合擊機制。
- **溫馨結局**：戰後，先前被勸退的所有舊 Boss 與骨盔哥布林齊聚山谷，點燃巨大營火舉辦「遲到一百年的慶功宴」。胖黃鳥蓋下《停戰協議》最後一個紅章；巨狼放下百年牽掛，主動俯低身子邀你再次上鞍——**「工作結束了，接下來，純粹去旅行吧。」**

## 五、Phase 6：通關後與 MMORPG 終局循環（Endgame）

1. **懷舊復健切磋場（高難度組隊刷裝副本）**：退休 Boss 們手癢懷念當年身手，每週輪換開放「全盛期切磋賽」（如不失聰的樹王、睡飽的霜龍，採類 Mythic+ 詞綴輪換），4–8 人組隊挑戰，掉落頂規古董神裝與限定外觀。
2. **迷路黃鳥的陳年包裹（隨機尋寶秘境）**：胖黃鳥的曾祖父當年遺失了數百個快遞包裹在隨機隱藏洞窟中，形成高重玩性的速通刷寶秘境，考驗體型差開路效率。
3. **旅人 × 巨狼雙軌 Build 深度構築**：於沙暴騎士長的「舊軍品改裝工坊」洗鍊詞綴、拼裝套裝。旅人流派（近戰短劍、遠程彈弓、機關陷阱、營火輔助）與巨狼流派（破甲重裝、疾風衝鋒、元素咆哮、載具支援）可自由混搭。
4. **魔物商店街與主城賽季建設**：全服玩家繳交舊軍品與特產推進建設進度，解鎖新店舖、鞍具掛飾與限定節慶（如「夏季瀑布洗狼節」「深秋骷髏洞營火祭」）。
5. **繪本旅記與野外營火社交**：收集全大陸手繪風景寫生與奇趣支線；野外入夜點起營火時，多組玩家與巨狼共同圍爐會觸發狼群互動彩蛋，並獲得組隊掉寶與移速加成。
