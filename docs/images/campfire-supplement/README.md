# 營火空地補充物件

以製作者選定的兩張湖畔營地日夜圖為構圖依據。四張 PNG 各展示一件物件，以中性日光呈現本色。日夜色調、營火反光及月光留待 Blender 或 Godot 打燈。下列為製作及擺位紀錄，現階段交付參考圖。

| 物件 | 圖片 | 建模及組裝 |
| --- | --- | --- |
| 白／藍圓球小花叢 | [參考圖](bobble-wildflowers.png) | 五枝高低錯落的細莖，三白兩藍。製作一個共根花叢 GLB，以 Godot MultiMeshInstance3D 在草地、洞旁及水岸疏落種植十多叢。 |
| 發條小兵原木凳 | [參考圖](campfire-log-seat.png) | 一截粗圓橫木直接貼地。先按小兵坐姿調整 CF-P04_旅記原木座；若底座外露或座面比例不合，再按圖製作獨立原木。 |
| 營火菱紋地毯 | [正上視圖](patterned-campfire-rug.png) | 沿用 1ea22cc3 素棕色地墊，依現有 UV 配紅底、菱形及邊框。若四角流蘇超出原輪廓，可用帶透明通道的小面片補足。 |
| 前景多葉圓灌木 | [參考圖](foreground-shrub.png) | 以自然綠色、前低後高的圓頭葉組成低矮葉團。與 CF-V01_掌葉小叢交錯擺在畫面邊角及水岸，以旋轉、縮放及材質色調製造變化。 |
