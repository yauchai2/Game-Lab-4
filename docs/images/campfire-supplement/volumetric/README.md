# 營火空地・立體重建參考圖

每件物件的各個視角均由同一份立體幾何以正交相機輸出。每張 PNG 只含一件物件，使用純灰背景與中性光照。hero.png 是斜視主圖，適合單圖生成。使用多視圖時，將同一資料夾的 front.png、right.png、back.png 分別放入正面、右側、背面欄位。各視角均獨立取景，請以斜視圖判斷整體比例。

| 物件資料夾 | 造型及使用方式 |
| --- | --- |
| wildflowers | 三白兩藍圓球，五枝細莖從根部向不同深度伸展。生成一叢 GLB 後，可用 Godot MultiMeshInstance3D 分散種植。 |
| log-seat | 無腳橫木。斜視圖同時展示端面年輪及樹皮長度。可先縮放 CF-P04_旅記原木座 試坐，再按需要採用獨立橫木。 |
| campfire-rug | 紅底金邊、菱紋、四角流蘇。微翹的一角用來展示布邊厚度；另附 top.png 對照紋樣。沿用 1ea22cc3 時，按原 UV 更新貼圖即可。 |
| rounded-shrub | 葉片沿根部四周分層向外生長。配合 CF-V01_掌葉小叢，於水邊交錯旋轉及縮放。 |

模型基礎材質以日光本色為準，夜間藍紫及營火橙光於 Blender／Godot 場景內調整。這批檔案為建模參考 PNG。
