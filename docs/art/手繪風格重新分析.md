# 《借影之森》手繪風格重新分析

主視覺採用**二維手繪繪本插畫**。先以大面積不透明水粉式色塊組織畫面，再在局部補上乾刷與方向性筆觸。把畫縮小時，應先讀到地形和角色動作。放大時，才看得到筆毛如何沿水勢、衣角和岩壁走。這些是根據成圖外觀所得的判斷。

## 第一版與參考圖的差距

| 項目 | 第一版偏差 | 原圖證據與修正 |
|---|---|---|
| 人物佔比 | 旅人與角族旅人接近角色特寫，面部和服裝搶過斷崖 | [瀑布木橋](原始圖片/08.jpg)的人只佔畫高約一成，巨崖與水簾先建立尺度。主視覺由小輪廓交代轉頭及跪下放梯，背包和雙角保留為識別形。 |
| 狼的造型 | 毛髮、肌肉和眼周刻畫近似寫實動物 | [花海騎狼](原始圖片/03.jpg)的狼靠水平長身、尖耳、楔形長嘴和灰紫面成立。先畫深靛輪廓，臉和腿只分出幾塊灰紫面。 |
| 岩壁與水霧 | 石頭裂成大量碎面，亮霧的變化蓋過斷崖邊 | [紅岩歇腳](原始圖片/05.jpg)用大斜面和成組短排線，[瀑布圖](原始圖片/08.jpg)將水畫成淺青大面，垂直乾筆和底部白弧各自有方向。岩壁每塊以兩三面起稿，水霧留下幾塊連續形。 |
| 光色 | 米金色遍及石面、服裝與遠景，壓縮冷暖對比 | [林中營火](原始圖片/13.jpg)讓冷靛和亮青佔大面積，暖橙只圍住火與角色。白瀑谷主要用青、靛與淡紫，暖色落在承接狼影的岸面及晚餐布包。 |
| 投影 | 第一版影子的奔跑輪廓清楚，可保留這項敘事設計 | [俯視騎狼](原始圖片/11.jpg)讓影子沿乾淨的暖地拉長。先確定長嘴、雙耳與尾巴能在縮圖辨認，再用少量乾邊將影子接回地面。 |

## 後續生成與驗收

- 先以 160 px 短邊看構圖。瀑布、兩岸的空隙、坐狼和放梯的動作各自須能辨認。
- 人物以平塗形體、厚底短靴、少量眼口與衣褶交代姿勢。花草先分組留白，前排用大葉，中段疏點，遠景合為色帶。
- 乾刷跟隨材質方向，水直、岸壁順切面、織物短斜。把筆觸集中於轉折、受力點及畫面邊緣。
- 審核借影時，以雙腳為投影起點，檢查奔跑的頭、耳、身體、四肢與尾巴是否清楚。重畫版在人景比例和色塊上已拉近參考圖，影子的前肢與嘴部仍可再清楚一些。
