# 湖畔植栽與巨狼實作

2026-11-22 · `feat/act1-diorama`

## 畫面方向

湖畔使用斜俯透視、移軸模糊與自然曲線的地形。深色林冠框住較亮的木屋、營火與溪流。樹冠以深青綠為主，局部選用較亮的黃綠。植栽沿岸、林緣與路旁成組落地，維持步道和水線的可讀性。

[little joy 原帖](https://x.com/shoejaat/status/2122368765497319704)展示森林、沙地、海島與小城，並說明已有地形、水、體積雲和光照系統。[地形工具示範](https://x.com/shoejaat/status/2122705569396228598)顯示平滑地形、草地及砂地筆刷、水邊與植栽的關係。這些資料足以確認可見的風格和功能。原作樹木網格、葉片 Shader 和風場算法仍待作者公開確認。

## 葉團、細葉和風

- [Eduardo Schildt 教學](https://www.youtube.com/watch?v=iPbYzFWECz4)、[示例專案](https://pixelagegames.itch.io/3d-pixelart-vegetation)及[Pontus Karlsson 教學](https://www.youtube.com/watch?v=iASMFba7GeI)提供參考。Eduardo 用分布在立體樹冠中的朝鏡頭葉卡，以及世界座標的移動噪聲。可見葉卡和負責地面投影的網格分開處理。這些是獨立實作的參考。
- 《補簽遠行》的闊葉樹以實體葉團保留俯視及背面體積。林緣加了一個以 `MultiMesh` 批次繪製的細葉簇，世界座標錨點與法線保持一致，輪廓由 Shader 剪裁，隨主鏡頭轉向。細葉簇與實體林冠共用遮擋淡化，投影由實體林冠負責。
- 針葉沿每一層的上下關係做頂點著色與不同傾斜的法線，明暗由枝層和場景主光共同決定。草團由交錯的曲面草葉組成，視角旋轉時仍看得到草簇。
- 樹冠、細葉和草共享移動的無縫噪聲，疊一層緩慢的波動。草根依 UV 固定，草尖與冠層取得不同振幅。日夜共用網格與風場，換色由一套場景參數驅動。
- 批次和葉簇數量以湖畔鏡位為限。本版本以 GL Compatibility 渲染驗收，整片大型地圖的 GPU 預算仍需另行剖析。新增植栽以輪廓、材質家族和正常鏡位的細節密度驗收。規律的森林資產適合程序建模，Tripo 適合提供需要特殊造型的毛坯。

## 水岸層次

湖水深淺仍由原有的地形高度和場景深度控制。岸沫以高度貼圖的局部坡度估算水平離岸距離，讓明亮水唇和外側斷續泡紋沿自然曲岸分開。橋墩、礫石和浮標的接觸回饋繼續由原有方法控制。在平坦淺水區，估算包含最小坡度，並限制在岸邊的淺深度帶。

## 巨狼資產

營地使用創作總監提供的 Tripo GLB，正式資產為 [companion_wolf.glb](../../game/assets/models/campfire/companion_wolf.glb)。原檔帶骨架、嵌入底色和四足步行動畫。湖畔採用站姿和局部的 Shader 呼吸，腳位與碰撞保持固定。四足步行素材保留在原 GLB，待巨狼移動玩法接入時使用。正式場景讀取嵌入的貼圖，Godot 同時保存匯入時所需的材質相關資源。

## 檢視

進入 `game/project.godot` 按 F5。以 R 比較環繞和跟隨，再用 N 檢查日夜。從橋頭和木屋後方看闊葉樹的細葉層與角色淡化。從營火旁看巨狼腳位及近身碰撞。獨立植栽樣板可由 `res://diorama/foliage/FoliagePreview.tscn` 按 F6 開啟，空白鍵切換風效。
