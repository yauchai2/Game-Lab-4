## 一、草地與樹木微風吹動完整管線（Blender 4.x → Godot 4.6）

本套管線將「公告板朝向鏡頭（Billboard）＋統一受光陰影（`LIGHT_VERTEX`）＋共用世界風場（Shader Globals）」結合《補簽遠行》的水粉乾刷遮罩，實現不閃爍、完美融入地面的手繪風植栽。

### 1. Blender 4.x 基礎模型製作規格（可供 AI 直接寫 Python 腳本生成並匯出 GLB）
- **草地卡片（`Grass_Card`）：**
  1. 建立 `0.5m` 平面（Plane），沿 X 軸旋轉 `90°` 並 Apply Transform，將底邊對齊 `Z = 0` 且 Origin 置於底部中心。
  2. 建立一個臨時水平面，使用 **Data Transfer** 修改器將水平面的 `Face Corner Custom Normals` 轉移至草地卡片（使所有草葉法線垂直朝上，與地表受光一致），套用後刪除臨時平面。
  3. 匯入 Godot 後將草卡網格存為獨立 `ArrayMesh`，再以 `MultiMeshInstance3D`（或外掛 Spatial Gardener）大面積佈植。
- **體積感樹冠（`Tree_Canopy`）：**
  1. 以球體搭配 `Displace`（Clouds 雜訊）與 `Remesh`（Smooth）做出蓬鬆低模樹冠並套用。
  2. 刪除原有 UV，重新建立一個讓**每一個四邊形面皆獨立鋪滿 `0~1` 完整 UV 空間**的 UV Map（`Reset UV`）。
  3. 另複製一份不套用葉卡位移的同輪廓簡模，作為 Godot 內的靜態投影代理（Shadow Proxy）。

### 2. Godot 4.6 全域風場參數（Project Settings → Shader Globals）

| 全域變數名稱 | 型別 | 說明 |
| :--- | :--- | :--- |
| `wind_noise` | `sampler2D` | 無縫 `NoiseTexture2D`（以 `FastNoiseLite` 生成，啟用 Repeat） |
| `wind_direction` | `vec2` | 世界 XZ 平面標準化風向（零向量時關閉滾動） |
| `wind_scale` | `float` | 世界公尺對應至雜訊 UV 的縮放倍率 |
| `wind_speed` | `float` | 風團沿世界平面推進速度（m/s） |
| `wind_strength` | `float` | 全域風力強度倍率（各材質再各自控制最大位移／旋轉角） |

### 3. `Grass.gdshader` 與 `TreeLeaves.gdshader` 核心邏輯
- **共同規格：**
  - 以 `ALPHA_SCISSOR_THRESHOLD`（初值約 `0.5`）裁切手繪黑白遮罩圖；設定 `SPECULAR = 0.0`（或 `specular_disabled`）避免塑膠反光。
  - 在 `light()` 中實作可調步數的色階化受光（`ceil(clamp(NdotL, 0.0, 1.0) * steps) / steps`），且**地面 Shader 的底色與 `light()` 公式須與草地同步**，草根才能無縫融入地面。
- **草地（`Grass.gdshader`）：**
  - 套用 `Y-Billboard (Keep Scale)` 矩陣保持垂直朝向鏡頭。
  - 於 `vertex()` 將實例根部座標（`NODE_POSITION_VIEW` 或 MultiMesh 實例原點轉 View Space）透過 `varying` 寫入 `fragment()` 的 `LIGHT_VERTEX`，確保整叢草作為單一單位統一受影、不出現雜亂陰影鋸齒。
  - 依未變形的世界 XZ 座標採樣全域 `wind_noise`，沿 Billboard 本地 X 軸左右搖擺（防順風變薄消失），並以根頂權重（UV 根部為 1、梢端為 0 時用 `1.0 - UV.y`）鎖死草根不滑移。
- **樹冠葉片（`TreeLeaves.gdshader`）：**
  - 於 `vertex()` 先將展開前的原始頂點 `MODELVIEW_MATRIX * vec4(VERTEX, 1.0)` 傳給 `LIGHT_VERTEX`，保留完整球體大色階與受光側微弱邊光（Rim Light）。
  - 將每面 `0~1` UV 映射至 `-1~1`，依世界 XZ 採樣全域風場在平面內施加微幅反向 XY 位移模擬葉片輕轉，最後乘上相機朝向矩陣並依 `leaf_scale` 展開為葉卡。
- **防閃爍樹影與渲染器備忘：**
  - 動態葉卡設為 `Cast Shadow = Off`，由同位置粗樹冠靜態代理設為 `Shadows Only`，徹底消除葉片搖動造成的樹影閃爍。
  - **Godot 4.6.3 渲染器提醒：** `GL Compatibility`（GLES3）於頂點階段產生陰影座標，片元改寫 `LIGHT_VERTEX` 不會重算陰影座標；若需完整「跨陰影交界整株統一受影」，須於獨立測試場景與 `Forward+` 進行視覺對照。

## 二、手繪筆觸與水粉質感的 AI 指令庫（Prompt Recipes）

### 1. 手繪草叢／樹葉黑白遮罩（給 `Grass.gdshader` / `TreeLeaves.gdshader` 的 `alpha_texture`）
> `Pure white silhouette of a stylized hand-painted clump of foliage leaves with rough dry-brush gouache edges, centered on a solid pure black background, high contrast 2D alpha mask texture, flat white shape, no grey gradients, no shadows, clean game asset alpha card`

### 2. Amelicart 水粉繪本 3D 微縮資產（適用圖像生成與 Tripo3D／Meshy 貼圖）
- **正向提示詞：**
  > `[Subject], 3D diorama in the style of Amelicart storybook illustration, chunky low-poly geometric shapes, flat-shaded facets, hand-painted dry-brush gouache texture, chalky pastel grain, lineless color blocking with subtle hand-drawn hatching lines, soft warm volumetric sunlight beams, stylized colored shadows, charming miniature 3D toy aesthetic, matte finish`
- **負面提示詞（避免變回塑膠 CGI）：**
  > `photorealistic, smooth plastic, glossy CGI, raytracing shadows, hyperdetailed, Unreal Engine 5 realism, Octane render shine, airbrushed, smooth gradients, heavy black outlines`
- **3D 貼圖專用詞：**
  > `hand-painted diffuse texture, visible brushstrokes, stylized gouache painting, baked ambient occlusion, no metallic, high roughness`

### 3. 立體筆觸面片（Brushstroke Alpha Cards）進階技巧
於模型輪廓外圍疊加少量彎曲 Plane 載入油畫／水粉筆刷 Alpha Mask，在 Blender 設定 `Render Method = Blended`（或 Alpha Hashed）、關閉背面顯示與 `Ray Visibility > Shadow`，即可在不產生黑影的情況下柔化 3D 模型生硬邊界。

## 三、Blender 4.x 手繪油畫／水粉程序化材質 Python 腳本

適用 Blender 4.x（EEVEE / EEVEE Next），可快速為模型套用「座標筆觸扭曲（Vector Distortion）＋色階柔和光影（`Shader to RGB` + `ColorRamp`）＋微弱自發光消除死黑陰影＋厚塗微凹凸（Impasto Bump）」；若要更貼近《補簽遠行》的乾刷水粉感，可將 `Voronoi` 改接拉長方向的 `Noise Texture`（`Detail = 12`、`Roughness = 0.85`）並將 `Roughness` 設為 `1.0`、`Specular IOR Level` 設為 `0.0`。

```python
import bpy

def create_painterly_material():
    obj = bpy.context.active_object
    if not obj:
        print("請先選取一個 3D 物件！")
        return

    mat_name = "Painterly_Oil_Material"
    mat = bpy.data.materials.get(mat_name) or bpy.data.materials.new(name=mat_name)
    mat.use_nodes = True
    nodes = mat.node_tree.nodes
    links = mat.node_tree.links
    nodes.clear()

    output = nodes.new('ShaderNodeOutputMaterial')
    output.location = (900, 0)

    # 座標與筆觸扭曲 (Brushstroke Distortion)
    tex_coord = nodes.new('ShaderNodeTexCoord')
    tex_coord.location = (-1100, 0)

    mapping = nodes.new('ShaderNodeMapping')
    mapping.location = (-900, 0)
    mapping.inputs['Scale'].default_value = (1.0, 1.0, 3.5)

    noise_distort = nodes.new('ShaderNodeTexNoise')
    noise_distort.location = (-700, 200)
    noise_distort.inputs['Scale'].default_value = 18.0
    noise_distort.inputs['Detail'].default_value = 6.0
    noise_distort.inputs['Roughness'].default_value = 0.65

    mix_vec = nodes.new('ShaderNodeMix')
    mix_vec.data_type = 'VECTOR'
    mix_vec.location = (-480, 100)
    mix_vec.inputs['Factor'].default_value = 0.04

    # 基底手繪色彩變化（可替換為 Image Texture 並接上 Mix Vector）
    voronoi_paint = nodes.new('ShaderNodeTexVoronoi')
    voronoi_paint.location = (-250, 250)
    voronoi_paint.feature = 'F1'
    voronoi_paint.inputs['Scale'].default_value = 25.0

    color_ramp_base = nodes.new('ShaderNodeValToRGB')
    color_ramp_base.location = (-30, 250)
    color_ramp_base.color_ramp.elements[0].position = 0.2
    color_ramp_base.color_ramp.elements[0].color = (0.18, 0.35, 0.55, 1.0)
    color_ramp_base.color_ramp.elements[1].position = 0.8
    color_ramp_base.color_ramp.elements[1].color = (0.85, 0.65, 0.45, 1.0)

    # 接收光影轉為柔和色階 (EEVEE)
    diffuse_bsdf = nodes.new('ShaderNodeBsdfDiffuse')
    diffuse_bsdf.location = (-250, -100)

    shader_to_rgb = nodes.new('ShaderNodeShaderToRGB')
    shader_to_rgb.location = (-30, -100)

    color_ramp_light = nodes.new('ShaderNodeValToRGB')
    color_ramp_light.location = (180, -100)
    color_ramp_light.color_ramp.interpolation = 'EASE'
    color_ramp_light.color_ramp.elements[0].position = 0.25
    color_ramp_light.color_ramp.elements[0].color = (0.55, 0.52, 0.62, 1.0)
    color_ramp_light.color_ramp.elements[1].position = 0.75
    color_ramp_light.color_ramp.elements[1].color = (1.0, 0.98, 0.92, 1.0)

    mix_color = nodes.new('ShaderNodeMix')
    mix_color.data_type = 'COLOR'
    mix_color.blend_type = 'MULTIPLY'
    mix_color.location = (460, 100)
    mix_color.inputs['Factor'].default_value = 0.75

    bump = nodes.new('ShaderNodeBump')
    bump.location = (460, -200)
    bump.inputs['Strength'].default_value = 0.15
    bump.inputs['Distance'].default_value = 0.02

    principled = nodes.new('ShaderNodeBsdfPrincipled')
    principled.location = (650, 0)
    principled.inputs['Roughness'].default_value = 0.92
    principled.inputs['Specular IOR Level'].default_value = 0.1
    principled.inputs['Emission Strength'].default_value = 0.25

    links.new(tex_coord.outputs['Object'], mapping.inputs['Vector'])
    links.new(mapping.outputs['Vector'], noise_distort.inputs['Vector'])
    links.new(mapping.outputs['Vector'], mix_vec.inputs[4])
    links.new(noise_distort.outputs['Color'], mix_vec.inputs[5])

    links.new(mix_vec.outputs[1], voronoi_paint.inputs['Vector'])
    links.new(voronoi_paint.outputs['Distance'], color_ramp_base.inputs['Fac'])

    links.new(diffuse_bsdf.outputs['BSDF'], shader_to_rgb.inputs['Shader'])
    links.new(shader_to_rgb.outputs['Color'], color_ramp_light.inputs['Fac'])

    links.new(color_ramp_base.outputs['Color'], mix_color.inputs[6])
    links.new(color_ramp_light.outputs['Color'], mix_color.inputs[7])

    links.new(voronoi_paint.outputs['Distance'], bump.inputs['Height'])

    links.new(mix_color.outputs[2], principled.inputs['Base Color'])
    links.new(mix_color.outputs[2], principled.inputs['Emission Color'])
    links.new(bump.outputs['Normal'], principled.inputs['Normal'])
    links.new(principled.outputs['BSDF'], output.inputs['Surface'])

    if obj.data.materials:
        obj.data.materials[0] = mat
    else:
        obj.data.materials.append(mat)
    print("手繪油畫材質建立完成！")

create_painterly_material()
```
