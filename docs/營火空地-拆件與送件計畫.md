## 沿用與程序製作

| 畫面元素 | 分工及處理方式 |

| 棚腳與溪岸散岩、零星花葉 | 優先試用[既有 GLB 庫](../美術參考/西岸港城/Tripo回傳/README.md)的 N05 灰紫岩、N02 圓團灌木、N03 花叢及 N04 寬葉地被。岩石可旋轉、半埋；花草縮小並減少數量，留出圖中的大塊空地。 |
| 小旅人、巨狼、胖黃鳥 | 沿用已綁定 C01。巨狼、信使鳥共用雲丘鎮 CH-CHR02、CH-CHR03 的資產 ID 和既有送件圖；以 GLB 回傳作為角色整合前置。岩棚內側設狼休息點，旅人與鳥在狼腹朝火的一側，三者保持獨立節點。 |
| 營地地面、林徑與溪岸 | Codex 用 Blender 建一片連續低模地表，沿左下溪線降坡。用頂點色或遮罩分出草、土和岸面，林徑接右上出口。Godot 以簡化地形作碰撞與導航，避免圖上的筆觸變成高低落差。 |
| 溪水與倒影 | Blender 依岸線鋪一條水面；Godot 水材質放少量橫向紫藍波紋，靠火一側加兩三筆橙色反光，以火光強度控制。溪岸作行走邊界。 |
| 火焰、煙、飛灰與火光圈 | Codex 在 Godot 建可獨立播放的營火節點。用雙色火舌卡、細曲線煙帶、少量粒子，柴堆作固定定位點。以局部光和地面遮罩控制暖光範圍，轉晨時一起淡去，留下輕煙。 |
| 小草筆觸與遠景 | 稀疏草簇用 GPT Image 畫遮罩，Blender 製底根固定的草卡，Godot 按區域散布與驅動風。遠景林影用少量卡片；前景實體樹和岩棚用簡化靜態投影，避免葉動令地面出現碎影。 |

## 組裝順序與可行走區

1. 先鎖遊戲的正交斜俯相機，用約 18 × 12 m 的灰盒還原全景。以畫面位置標記棚口（左上）、火心（中央略下）、睡墊與行囊（右中）、溪岸（左下）、出口（右上）。座標以實機相機投影對照原圖。
2. 第一批畫 R01、T01、F01，共 7 張。匯入後先走「棚口 → 營火旁 → 右上林徑」。主路試留約 3 m 淨寬，棚前留巨狼轉身及鼻推的側向空間。岩棚只阻擋岩壁與側腳；可走區延伸到棚簷下角色休息處。柴堆中心設小阻擋，火光圈可走。
3. 第二批畫 P01、P02，共 4 張。把睡墊與行囊放在主路側邊，按 C01 身高試比例，再放 T02、V01（第三批，共 2 張）。前景樹冠若蓋住鼻推、起身或出口，優先微調位置或在角色經過時淡化。
4. Godot 將棚前設為出生演出區，右上林徑接雲丘鎮。標題畫面讓狼蜷起護住旅人；開始後 2 秒內從深藍夜色轉金橘晨光，火焰熄成薄煙。旅人起身，狼打哈欠並輕推；向鎮口移動時銜接鑼聲及配樂切換。
5. 同一相機各驗收一張夜景與晨景。檢查棚內狼耳與岩頂距離、棚口出入、巨狼轉身、裝飾遮擋、溪邊碰撞、林徑出口及返回落點。遠看先讀到營火與棚口，再讀到去鎮上的路。

## 圖片及模型交接

單件圖片用 GPT Image 生成，維持寬色塊、鈍輪廓、少量乾刷和可愛比例。採中性光、單色背景，夜色由場景光照建立。火光反射、地面、角色和鄰件留給組裝。三視同設計、同尺度與基線，**一張 PNG 一件一視角**，獨立命名如 CF-R01_front.png、CF-R01_left.png、CF-R01_back.png、CF-F01_oblique.png。補圖另標 qa，不混入基本圖數。打包時按 ID 建資料夾，清冊記錄方向、來源與原生尺寸。

GLB 回傳後保留原檔，在 Blender 校正單位、接地原點、開口和法線。岩棚碰撞用多個簡化塊保留入口；樹木優先只擋樹幹，草葉與遠景不設碰撞。Godot 再調材質、動畫和固定鏡頭下的可讀性。
