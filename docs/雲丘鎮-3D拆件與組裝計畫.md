# 雲丘鎮｜3D 拆件、Tripo3D 送件與組裝計畫

適用於《補簽遠行》的雲丘鎮安全區 `CloudhillTown.tscn`。以下以[雲丘鎮斜俯全景原圖](images/cloudhill-town-assembly-reference.png)的擺位、剪影與色調為基準。鎮口清倉行、中央金羽驛站、公會、老鐵平台、波波服務攤、住宅、退休頭目預留空地及東側石拱均納入這張地圖。西南林徑接營火地圖，東側石拱接雲海古道。枯木教學、窄門和哨長戰鬥由雲海古道場景承接。

## 1. 製作分工

| 由誰製作 | 適合的部分 | 交付 |
| --- | --- | --- |
| GPT Image → Tripo3D | 有獨特剪影、有機形體、水粉表面或需環看外觀的資產。包括公會外殼、住宅、角色、鞍座與手持主道具。 | GPT Image 獨立送件圖，由使用者送 Tripo 匯出 GLB。 |
| Codex ＋ Blender | 需要對尺寸、開口、榫接或接地負責的結構，以及規則幾何。包括兩個攤位、石拱、階梯、牆與欄杆、木箱、可開寶箱、驛站。 | 可編輯網格、按用途分件的 GLB。 |
| Codex ＋ Godot | 地面、路線、台地標高、可行走區、碰撞、導航、傳送、光照、植栽散布及互動。 | 場景與組件，視覺網格、遊戲碰撞和互動分開。 |
| 既有資產 | 現成 C01 旅人骨架與外圍裝飾先按比例核對。 | 使用已收錄的原檔，視覺方向有需要再換材質。 |

首輪預計 **12 個新 Tripo3D 母件**。其中 9 件三視圖、3 件單張斜角，合計 **30 張基本輸入圖**。第四視圖或頂視依驗收補上。4 棟住宅由兩個母件配色和轉向重用。攤位的開口與接點由 Blender 控制，日後如需要 GPT Image 圖，提供外觀參考而不增加兩個整攤 Tripo 任務。

BLO 類為精確結構。GOD 類為組裝、地形或作用範圍。道具子件可共用材質，依下表各自對齊原點及掛點。

| --- | --- | --- |
| CH-BLO01 | 格布清倉行 | 柱梁架、淺藍瓦棚、赭黃簾、低櫃、後掛架、價牌、銅鑼，各為可替換網格。木掛架的兩劍一盾用手作低模或主劍縮放換色，避免與牆合併。櫃檯面高 0.65–0.75 m 試起，按旅人撐櫃動作微調。牌面的 `-50¢` 用貼圖。 |

| CH-BLO03 | 金羽驛站 | 淺石圓台、短青座、金羽徽記三件。羽毛可移動，發光由材質和粒子控制。圓台標出可繞行空間。 |

| CH-BLO05 | 西南林口雙石柱 | 一個母件鏡像共用。柱身、帽石和可選旗面，視覺角色是標明進鎮點。 |

## 4. 組裝起點與分區接合

全圖暫以 **48 × 34 m** 作第一輪灰盒參考，單位 1 m。原點在圖面示意的西北角，`+X` 朝東、`+Z` 朝南、`+Y` 向上。主廣場與主路標高先設 Y 0。北側住宅台地和老鐵平台先用約 +1.2 至 +1.5 m。下表是組裝錨點參考，保持概念圖的相對關係便可按通行調整。

| 區塊 | 示意 (X, Z) | 組裝要點 |
| --- | --- | --- |
| 西南林口 → 櫃前 | (3, 31) → (10, 26) | 雙石柱淨空先抓 3.6 m。清倉行退到路西側，巨狼草墊在攤旁，留可從主路接近的肩側。 |
| 公會及老鐵 | (16, 10)、(7, 14) | 公會門前有接待平台。老鐵台地的寶箱和靶位靠內側，避免訓練時擋梯口。 |
| 中央廣場 | (24, 21) | 驛站可四周繞行，邊緣留通向兩側服務點的分岔。 |
| 波波、住宅及預留地 | (32, 17)、北側與右下、(37, 12) | 波波櫃檯面向主路。住宅門前與階梯留出落腳面，預留地可日後放攤。 |
| 東側出發拱門 | (44, 7) | 拱前保留載人巨狼轉向及傳送緩衝區。兩向到達點與離開區分開，避免回鎮立即傳回野外。 |

先用簡模走一遍「林口 → 清倉行 → 驛站 → 波波 → 東拱門」，再從廣場上老鐵平台、到公會門前。主路淨寬以 3.5–4.0 m 試作；以旅人碰撞直徑 0.60 m、巨狼 1.64 m 為測試起點，再用實際模型與騎乘姿勢覆核階口、轉角、鞍側與拱門。相機下取得可讀的剪影後才加裝飾。

## 5. GPT Image 送件規格

1. **一個 ID 對應一個獨立主體。** 角色連身衣物可合出圖，骨盔、鞍、劍與可替換道具各自出圖。公會門口前的階梯、旗、角色、植栽由場景另外裝。先用全景確定配色，另以資產卡鎖定尺寸、姿勢、正向與開口。
2. **正式送件圖由 GPT Image 生成。** 若先做 Blender 幾何底稿，僅用於約束輪廓、量測與人工核對。全景可作整體風格和位置參考。交付獨立 PNG 並記錄來源；如採同張母稿拆格，附上原稿與實際裁圖解析度。
3. **同件三視圖使用同一正交比例。** 正／左／背同解析度、同 px/m、共用接地線與中性光。正面水平，背面相差 180°，左側相差 90°。4 張的件補右側。頂、底和 45° 斜角用於人工驗收，依使用中的 Tripo 介面能否接收再選。
4. **單圖採正交 3/4。** 建築、道具露正面、側面及適量頂面。讓入口、輪廓、薄厚與底面落點讀得清楚。出圖以 1536 或 2048 方形 sRGB PNG 為目標，原生尺寸、拆格與重採樣如實記錄。純淺中灰底、四周留白，各件完整入鏡，燈光色中性。
5. **檢查同一物件的吻合。** 用窗位、門洞、屋脊、骨骼關節、耳尾、鞍面或護手作基準點，正背輪廓的高度與落地線一致。視圖單獨上傳，標線、拼版與設計說明放驗收資料。命名如 `CH-B01_front.png`、`CH-CHR02_left.png`、`CH-B02_oblique.png`、`CH-P01_qa_top.png`。

水粉材質用同一套大色面、短乾刷、少量紙紋。屋面、布與石頭保留可分辨的材質組。場景的暖晨與藍綠陰影留給 Godot 統一打光，避免烘進每件送件圖。[多視圖驗收參考](../美術參考/西岸港城/三視圖製作與驗收標準.md)

## 6. 交付順序與完成條件

1. **灰盒先鎖平面。** Codex 搭道路、標高、兩個出入口、清倉行櫃、驛站與老鐵平台；用角色替身試站位和可通行範圍。
2. **第一批出圖。** CH-B01 公會、CH-CHR01 格布、CH-CHR02 巨狼、CH-P02 短劍。先用公會驗證屋形和門口，用格布和短劍驗證櫃檯互動，用狼驗證上鞍尺度。
3. **第二批出圖。** 先按狼背定 CH-P01 鞍，再補骨盔、黃鳥、局長、老鐵、波波與兩款住宅。清倉行、驛站、石拱和地形可由 Codex 同期搭建。
4. **Tripo 回傳 → 組裝。** 核對資產 ID、實際尺寸、法線、UV、貼圖、材質、門洞、鞍面等結構及網格原點。角色核查蒙皮、尾翼與肢體姿勢。最後在正交鏡頭下測整條路、互動灰盒與雙向轉場，並確認畫面縮小後四個主要地標仍看得清楚。

目前為出圖與整合規劃。圖檔、模型、遊戲尺度及碰撞驗收會隨後續製作進度寫入清冊。
