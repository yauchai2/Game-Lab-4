新代理先讀 [共同協作指引](../AGENTS.md)，再按任務查閱下列文件。程式實況以接手版本及實際執行結果為準。

## 現行玩法方向

《邊境遠征》以大型獸伴、打怪刷裝與冒險為核心。玩家騎乘獸伴走遠路，靠雙方體型差開路，在戰鬥中讓獸伴製造機會，再用武器反擊並取得裝備。初版先做一至兩招合作技，序章用「獸伴撞斷頭目重砸、旅人持短劍近身反擊」驗證。借影玩法已退役，早期借影方案列入下方歷史記錄。

## 下一版序章〈借一晚火〉

- 使用者確定主角是初出茅廬的天真旅人。開場在第一座城市前的郊野，敵人是哥布林。獸伴從林邊衝出救人時撞開的是第一關頭目。荒廢營地提供近戰武器與盾。
- 暫定用一段 7–8 分鐘的可操作流程串起石橋遇險、騎乘離開、下騎穿窄縫開閘、拿短劍與圓盾、合力擊敗頭目、過一晚營火和進港城報到。獸伴在城門先回郊野，預計於進城後的首張委託重逢並正式加入。
- 教學暫定按遇敵時機逐一教移動與閃避、騎乘、開閘、舉盾與近戰，最後只教一招合作技。頭目重槌蓄勢時讓獸伴撞斷攻擊，旅人趁頭目踉蹌近身出劍。開場救援先示範同一動作。畫面採 16:9 固定斜俯正交視角，救援和營火可沿相同角度推近。
- 這是較早的序章草案。Gemini 的《補簽遠行》故事總綱、玩法和頭五分鐘分鏡收錄於[劇情設計分支](https://github.com/yauchai2/Game-Lab-4/tree/docs/story-worldbuilding-after-ceasefire)。

## Godot 專案狀態

港城巨蟹及《晚餐在對岸》斷崖灰盒均已從 `main` 移除。Godot 專案保留編輯器設定，目前沒有可執行的主場景。未提交的《補簽遠行》雲丘灰盒草稿也已刪除。

## 可沿用的港城美術資料

- 西岸港城首場景採「水粉平塗 × 幾何切面 × 繪本微縮感」。3D 資產以大切面、消光乾刷、無描邊與局部排線製作，暖光和有色陰影在 Godot 場景驗收。[西岸港城 3D 美術規格](../美術參考/西岸港城-3D美術規格.md)。後續資產採偏可愛、簡化的 Low-poly 比例。送件圖、實際狀態和下一件記錄於[西岸港城資產交接](../美術參考/西岸港城/README.md)。C01 已收錄創作總監提供的原始 GLB，Godot 確認保有 65 根骨骼與蒙皮，無內嵌動畫。
- 早期港城關卡方案曾將西岸港區接入橙瓦埠，串起登岸、食堂領糧、青眠林出發及返城驗傷。首輪以 B03 前廳、B04 用餐廳、B07 棚口及返城驗傷、辨刀為主。NPC、通行、林口與回程點見[首場景關卡與 NPC 計畫](../美術參考/西岸港城/首場景關卡與NPC計畫.md)。其中借影劇情與任務屬當時的設計，參考時可查場景配置與資產用途。
- 港城植栽準備試作 Billboard 草卡與葉卡、共用世界風場及靜態樹影代理。現有 GL Compatibility 不會用片元 `LIGHT_VERTEX` 重算陰影座標，待同景比較 Forward+。[植栽公告板與全域風場](../美術參考/西岸港城/植栽公告板與全域風場.md)
- 港城正式三視圖使用 GPT Image，Blender 渲染供幾何核對。B03–B08、S03–S05、C02、C03 已補齊 35 張 GPT Image 送件 PNG，並保留原稿；多視圖的 Tripo GLB 生成中。20 件單張送件 GLB 已按 ID 收錄，並通過 Godot 4.6.3 讀入及場景建立。[Tripo 回傳清冊](../美術參考/西岸港城/Tripo回傳/README.md) · [資產交接](../美術參考/西岸港城/README.md)

## 歷史記錄 · 《借影之森》

> 以下保留當時的企劃背景。

- 原創童話奇幻 MMORPG。以獸伴、借影及共同遠征為核心。四個重點是**簡約、氛圍、手繪感、人味**。以繁體中文書面語為主，英文作輔助。[核心企劃](../借影之森-MMORPG核心企劃.md)
- 一人擔任創作總監，由多個 AI 執行製作。Codex 與 Claude 可輪任主開發。Codex 生成圖片，Tripo3D 用於有立體需求的模型。使用者以 GitHub Desktop 同步原始檔，再用本機 Godot 試玩。[協作指引](../AGENTS.md)
- 先驗證單人斷崖玩法，再驗證雙人分路與會合。後續 MMO 功能、武藝與配裝按製作里程碑實作。[獨立開發製作企劃](../借影之森-獨立開發製作企劃.md) · [職業與配裝](../借影之森-職業與配裝企劃.md)
