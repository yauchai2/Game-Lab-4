## 湖畔營火微縮場景（feat/act1-diorama）

本分支的 F5 入口為 `res://diorama/LakesideView.tscn`，其中的 SubViewport 載入 `CampfireDiorama.tscn`。日景以創作總監提供的森林短片為美術參考。鏡頭採 22° 長焦透視，約 52° 斜俯，以 16 秒走完一圈。R 在環繞與跟隨之間切換，N 切換日夜，V 切換天氣，H 控制提示。

- **場景。** 紅瓦木屋移至河岸內側的平台，與營火同時入鏡。屋瓦使用錯縫的程序材質，木牆、窗框、階梯和煙囪以合併網格降低繪製次數。石橋的弧形橋面與玩家高度共用同一剖面，已用正常移動輸入跨橋。
- **森林與地形。** 共用網格分批繪製五層針葉樹與成簇闊葉樹，草叢、林冠與葉簇讀取同一張移動的世界座標風場。林緣的闊葉樹採實體葉團加朝向鏡頭的細葉簇，地面投影沿用實體林冠。溪岸有分段岩層，石環沿彎曲山徑以十塊不等寬、略有偏斜的埋入式岩階銜接營地。河岸和湖灣由連續的高度場過渡塑形，花草留於乾岸和步道兩側。地形取樣範圍比焦痕、積雪和足跡的狀態貼圖範圍大，兩者各自使用自己的座標規格。
- **解析度與微動。** 3D 以 960 × 540 繪製，再以最近鄰放大。世界 Viewport 關閉 MSAA 和螢幕抗鋸齒。HUD 在外層 Viewport 繪製。焦帶後段在中間調加入極淡的 4 × 4 Bayer 抖色。小旅人的 `traveler_c01_animated.glb` 沿用原骨架，重定向本機 Mixamo 待機及水平揮擊，走路則使用 [Carnegie Mellon University Graphics Lab Motion Capture Database](https://mocap.cs.cmu.edu/) 的第 7 位演員第 1 段步態，裁為循環、移除根部位移，再重定向到小旅人骨架。花束迎風彎曲，供應的巨狼模型以站姿留在營火旁，並有局部呼吸微動。揮擊中的木劍由手骨帶動。雪與雨使用 GPU 粒子批次，地表積雪和濕潤繼續由狀態貼圖記錄。
- **材質與特效。** 水色以高度場和深度緩衝共同判斷，石腳有深度白沫和局部波紋。樹隙光束使用交叉平面、加色混合與深度淡出。風線沿貝茲曲線前進，截面朝向鏡頭。煙囪、營火及瀑布使用粒子，煙霧隨日夜調色。

- **遊玩與可讀性。** 小旅人以膠囊碰撞沿橋欄、木屋、樹幹及主要道具滑動，橋面、碼頭和岩階獨立取步行高度。靠岸保留安全距離。物件遮住角色時按視線淡化，林冠以局部的抖色淡化減少遮擋。揮擊在動作接觸時判定方向與距離。命中後以較低彈跳的實體碎屑回饋，焦痕只保留於營火周圍。配樂、地面腳步、石面腳步、木板腳步和揮擊音訊見 [素材來源](../game/assets/audio/lakeside/CREDITS.md)。

特效以可讀的運動節奏為準。瀑布水簾、水花及向外散開的泡沫共用落點。小型火星和低幅火光閃動集中於營火。晴天花粉與夜間螢火以同一個 MultiMesh 批次淡入淡出。雨雪逐步降低直射光及光束強度，雨點亦在水面留下短暫的擴散圈。

Apple M4 上以 Godot 4.7.2 的 GL Compatibility 測試。已驗證 F5 場景、16:9 與 4:3 視窗、最近鄰像素取樣、日夜、晴雪雨、兩種鏡頭、跨橋及鍵鼠揮擊，並反覆擷取完整環繞檢查側面與背面。部分退出方式仍顯示兩個既有的 `AudioStreamGeneratorPlayback` 物件未釋放。

參考來源、技術選擇與局限見 [湖畔植栽和巨狼實作](art/湖畔植栽與巨狼實作.md)。獨立植栽樣板為 `res://diorama/foliage/FoliagePreview.tscn`。以程序網格建立闊葉樹、針葉樹與草團，風動權重存在 UV，配色存在頂點色。在樣板按空白鍵比較有風與靜止。樣板可供美術驗收，F5 入口仍為湖畔場景。

## 最新專案定調：《補簽遠行》（暫名，2026-11-19 定案）

- **語言規範**：所有對話、企劃與遊戲內正式文本統一以**繁體中文書面語為主，英文術語為輔助**。
- **核心敘事（輕鬆幽默反轉）**：百年前大戰早已結束，魔物全都退休轉行做生意，唯獨荒野深處的舊時代 Boss 因信使鳥路癡而未收到停戰通知。玩家作為「大和平旅務局（勸退公會）」專員，騎乘退休巨獸前往強制派信、辦理退休並回收百年庫存神裝。
- **核心鐵三角**：
  - **沉默小旅人（玩家）**：極少說話，透過誇張肢體動作、道具展示與頭頂極簡圖示泡泡（Emote Bubbles）表達情緒與回應。
  - **巨型動物夥伴**：起點為眼神冷靜、夜晚護人的退休斥候巨狼；隨進度可解鎖重甲巨熊、雲海巨鹿、沙暴大穿山甲等退休魔獸導遊。
  - **胖黃羽信使鳥**：負責遞交《停戰通知書》、在 Boss 破防歸零時俯衝蓋下巨大紅色「正式退休」章，兼任自動拾取與寶箱提示。
- **地圖架構（PoE 2 式獨立分區＋自然傳送點）**：
  - **地圖 1《林間營火空地》**：獨立深藍夜林起點，右側微光林徑傳送點前往小鎮。
  - **地圖 2《雲丘小鎮 Hub》**：緊湊型安全區城鎮（格布清倉行、咕嚕局長、老鐵石魔像儲物箱與試刀木樁、波波史萊姆移速 Buff、中央信使鳥驛站 Waypoint、退休 Boss 進駐空位），東側出發拱門傳送至野外。
  - **地圖 3《雲海古道與石橋》**：獨立野外冒險與首戰地圖（枯木路障 → 窄縫開石門 → 稻草人哨長首戰與蓋章退休 → 開箱取得《彈簧試驗鞍座》→ 雲海瞭望台與驛站 → 東側青苔石階傳送至第一章《翡翠天梯古林》）。

## 現行可玩灰盒原型：PoE 2 式三獨立分區地圖（F5 直接啟動）

- **主入口與跨圖狀態：** `game/project.godot` 已註冊 `PrologueState` Autoload（[PrologueState.gd](../game/prologue/PrologueState.gd)）與共用 2.5D 正交斜俯基底類別（[PrologueBase.gd](../game/prologue/PrologueBase.gd)），按 F5 直接啟動：
  1. **地圖一：林間營火空地**（[CampfireClearing.tscn](../game/prologue/CampfireClearing.tscn)）— 純深藍夜林、青苔骷髏洞、倒影夜溪、實機標題畫面、東側林徑自然傳送點。
  2. **地圖二：雲丘小鎮 Hub**（[CloudhillTown.tscn](../game/prologue/CloudhillTown.tscn)）— `36m × 24m` 多人尺度廣場、骨盔哥布林 `-50¢` 開放式清倉行、可進入藍門簾酒館大廳入口、中央信使鳥驛站（Waypoint）、南側雙飲水木槽＋雙試刀木樁＋儲物箱（Stash）＋清潔史萊姆波波（移速 +15% Buff）＋東側出發拱門傳送點。
  3. **地圖三：雲海古道與石橋**（[CloudhillRoad.tscn](../game/prologue/CloudhillRoad.tscn)）— 枯木路障 `Q` 撞碎、北側 1.4m 窄縫拉桿／南側 3.6m 巨狼雙扇木門、稻草人哨長首戰（60 FPS 整數幀 Hitstop、破防、胖黃鳥蓋「正式退休」紅章、橋頭即時展開茶攤）、《彈簧試驗鞍座》開箱試跳、雲海瞭望台拉遠鏡頭與驛站快傳回鎮、東側第一章青苔石階。
- 驗證狀態：已完成 GDScript 4.6 嚴格型別與跨場景切換靜態檢查；實機 F5 試玩手感待創作總監於 Godot 4.6.3 驗收。舊港城灰盒 [game/harbor/Harbor.tscn](../game/harbor/Harbor.tscn) 仍保留可供 F6 對照。
