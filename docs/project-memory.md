# 《借影之森》專案記憶

新代理先讀 [共同協作指引](../AGENTS.md)，再按任務查閱下列文件。程式實況以接手版本及實際執行結果為準。

## 已確認的方向

- 原創童話奇幻 MMORPG。以獸伴、借影及共同遠征為核心。四個重點是**簡約、氛圍、手繪感、人味**。以繁體中文書面語為主，英文作輔助。[核心企劃](../借影之森-MMORPG核心企劃.md)
- 一人擔任創作總監，由多個 AI 執行製作。Codex 與 Claude 可輪任主開發。Codex 生成圖片，Tripo3D 用於有立體需求的模型。使用者以 GitHub Desktop 同步原始檔，再用本機 Godot 試玩。[協作指引](../AGENTS.md)
- 先驗證單人斷崖玩法，再驗證雙人分路與會合。後續 MMO 功能、武藝與配裝按製作里程碑實作。[獨立開發製作企劃](../借影之森-獨立開發製作企劃.md) · [職業與配裝](../借影之森-職業與配裝企劃.md)

- 西岸港城首場景採「水粉平塗 × 幾何切面 × 繪本微縮感」。3D 資產以大切面、消光乾刷、無描邊與局部排線製作，暖光和有色陰影在 Godot 場景驗收。[西岸港城 3D 美術規格](../美術參考/西岸港城-3D美術規格.md)。後續資產採偏可愛、簡化的 Low-poly 比例。送件圖、實際狀態和下一件記錄於[西岸港城資產交接](../美術參考/西岸港城/README.md)。C01 沿用創作總監已有的模型。
- 港城關卡方案將西岸港區接入橙瓦埠，串起登岸、食堂領糧、青眠林出發及返城驗傷。首輪以 B03 前廳、B04 用餐廳、B07 棚口及返城驗傷、辨刀為主。NPC、通行、林口與回程點見[首場景關卡與 NPC 計畫](../美術參考/西岸港城/首場景關卡與NPC計畫.md)，待港城灰盒驗證。
- 港城植栽準備試作 Billboard 草卡與葉卡、共用世界風場及靜態樹影代理。現有 GL Compatibility 不會用片元 `LIGHT_VERTEX` 重算陰影座標，待同景比較 Forward+。[植栽公告板與全域風場](../美術參考/西岸港城/植栽公告板與全域風場.md)

## 目前可玩內容

Godot 4.6.3 的單人斷崖灰盒《晚餐在對岸》已能執行。主場景為 `Cliff.tscn`，關卡規則在 `Cliff.gd`，溪水材質在 `Creek.gdshader`。試玩入口見 [Godot 專案](../game/project.godot)。

- **借影路線。** 在左岸營火按 E 借影，走至起跳木臺，按空白鍵過崖，在對岸木臺按 E 放下踏板。等狼會合後，到右岸營火按 E 歸還並完成。
- **溪路。** 可全程陪幼狼沿下方溪路走。於足印旁按 E 記錄，到右岸營火完成。兩條路皆可按 R 重新開始。WASD 或方向鍵移動，Q 切換等候及跟隨。
- **既有驗證。** 曾在 Linux 的 Godot 4.6.3 渲染斜俯鏡頭，並以自動操作回歸兩條路線。路線回歸用原攝影機方向驅動既有移動序列。新鏡頭下的輸入手感仍待使用者本機試玩。

## 試驗與待驗證

- **美術方向。** 最新灰盒試驗為 3D 微縮場景與固定斜俯正交鏡頭。地形、樹、岩與角色用立體替身。正式材質及角色呈現待實機確認。先檢查斷崖落點、溪路、留在對岸的狼是否同時清楚。[鏡頭與核心玩法](../借影之森-鏡頭與核心玩法.md#立體微縮場景方向)
- **試玩。** 目標是五位初見者中至少四位能自行解釋借影代價、會合及歸還。記下玩家回頭接狼的原因與是否願意交換路線。[開工決策與首輪試作](../開工決策與首輪試作.md)
- **階段。** 戰鬥、雙人連線、持久化和正式美術仍在規劃或待實作。下一項任務依使用者給定的優先次序開始。

## 更新方式

把長期有效的資訊寫在最接近該決定的規格內，再在此頁更新摘要和連結。方向被修正時，更新舊條目並簡述理由。無法驗證的項目標記「待驗證」，附上可重現步驟。交接訊息以四項為主：分支與提交、改動與檔案、實測結果、下一個待處理事項。
