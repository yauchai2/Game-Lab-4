## 最新專案定調：《補簽遠行》（暫名，2026-11-19 定案）

- **語言規範**：所有對話、企劃與遊戲內正式文本統一以**繁體中文書面語為主，英文術語為輔助**。
- **核心敘事（輕鬆幽默反轉）**：百年前大戰早已結束，魔物全都退休轉行做生意，唯獨荒野深處的舊時代 Boss 因信使鳥路癡而未收到停戰通知。玩家作為「大和平旅務局（勸退公會）」專員，騎乘退休巨獸前往強制派信、辦理退休並回收百年庫存神裝。
- **核心鐵三角**：
  - **沉默小旅人（玩家）**：極少說話，透過誇張肢體動作、道具展示與頭頂極簡圖示泡泡（Emote Bubbles）表達情緒與回應。
  - **巨型動物夥伴**：起點為眼神冷靜、夜晚捲身護人的退休斥候巨狼；隨進度可解鎖重甲巨熊、雲海巨鹿、沙暴大穿山甲等退休魔獸導遊。
  - **胖黃羽信使鳥**：負責遞交《停戰通知書》、在 Boss 破防歸零時俯衝蓋下巨大紅色「正式退休」章，兼任自動拾取與寶箱提示。
- **視覺與視角**：固定斜側 2.5D 正交視角；手繪水粉／乾刷蠟筆繪本風格（參考 `@amelicart` *A Little Journey This Way*），主打暖色白晝與深藍營火夜晚的強烈對比。

## 下一階段製作目標：序章黃金五分鐘（`PrologueCloudhill.tscn`）

- 依 [序章黃金五分鐘分鏡與實作規格](序章黃金五分鐘分鏡與實作規格.md) 實作連續單場景（A 區林間營火空地標題無縫切換晨光 → B 區骨盔哥布林清倉行 → C 區枯木衝撞與窄縫石門開閘 → D 區雲海石橋稻草人哨長首戰與蓋章退休 → 掉落首件改變手感的神裝《彈簧試驗鞍座》 → 雲海全景瞭望台）。
- 技術規範：Godot 4.6.3、固定斜側 2.5D 正交視角、破防打擊停頓（Hitstop）採用 **60 FPS 整數幀計數器（Integer Frame Counter）**，不改動 `Engine.time_scale`。
- 視覺概念圖：林間營火空地 2.5D 無角色概念圖已生成，可作為 A 區打光與構圖基準。
- B 區已有 [雲丘鎮口清倉行規劃與出圖簡報](雲丘序章-B區骨盔哥布林清倉行.md)，記錄櫃檯、巨狼休息位、A–C 動線及完整場景主圖構圖。[B 區 GPT Image 概念圖](images/雲丘序章-B區清倉行-場景概念.png)已收錄，尺寸為灰盒試作值。
- 雲丘鎮全景已有 [3D 拆件與組裝計畫](雲丘鎮-3D拆件與組裝計畫.md)。新模型以三地圖分區的雲丘安全區為準，可見資產預設採 Tripo3D（36 個母件、77 張基本送件圖），Codex 在 Blender 校正接合與分件，在 Godot 組裝通行與互動。 [全套 GPT Image 送件 ZIP](https://github.com/yauchai2/Game-Lab-4/archive/refs/heads/downloads/cloudhill-tripo-images.zip) 已收錄 77 張基本圖、5 張驗收補圖與原稿。[分類裁切圖 ZIP](https://github.com/yauchai2/Game-Lab-4/archive/refs/heads/downloads/cloudhill-tripo-cropped.zip) 可直接按資產選取獨立 PNG。Tripo GLB 待回傳後按 ID 登錄和驗收。
