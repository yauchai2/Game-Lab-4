# 雲丘序章 B 區｜骨盔哥布林清倉行

本區接在營火醒來之後、枯木教學之前。玩家沿林徑走出陰影，第一眼看到骨盔哥布林熱情招呼，身後一整排舊軍品都掛上了折扣牌。片刻後，玩家親手買到短劍，走兩步就能上鞍前往石橋。採一段連續戶外場景，依序讀到**大折扣牌、櫃檯上的短劍、旁邊的巨狼、往右上方的道路**。

## 平面與通行

第一輪灰盒以 **22 × 14 m** 規劃 B 區，座標為本區相對值。X 向東、朝 C 區，Z 向南、朝前景。主路與店前交易區同一高度。路線在畫面上從左下通往右上。

        ┌──────────── 北側木攤 ────────────┐
        │ 骨盔店徽     武器掛牆      庫存箱 │
        │ 店主出迎點   店主交易站位          │         乾草休息位
        └─────────── 低木櫃檯 ────────────┘         巨狼／上鞍
                         旅人交易位  E                   ↑ F

A 區林徑 ────── 店前主路 ──────────────────────────── ↗ C 區枯木道

**可走**範圍包括林徑、店前主路、櫃檯前及狼旁空地。後牆、櫃後庫存和高坡以木箱、低欄與灌木明確收邊。購買前能走近 C 區，前方既有枯木障礙形成自然停點，回頭便看得到攤位。

0:45–1:45 是節拍目標。入場、購買及上鞍由玩家操作推進，演出時間隨走路與停留調整。

| 店主出迎 | 哥布林在入口揮手：「早安早安！百年戰爭早打完了，魔王軍滯銷武器全場五折！走過路過別錯過！」同一頭巨狼走到攤右側乾草地，趴下短暫打盹。 | 第一個氣泡留在哥布林骨盔上方，避開折扣牌。走近櫃檯才顯示 E。 |

## 美術配置

- **木攤輪廓。** 歪斜而厚實的木柱、短瓦頂、前端收起一側的赭黃布簷。前方開敞，靠邊柱與斜撐交代屋頂支撐，確保斜俯鏡頭能看到武器牆和店主。店徽用鈍圓骨盔和木雕價牌組成，第一眼可看出攤販身份。
- **商品牆。** 木掛牆上用約 6–8 件形狀分明的短劍、圓盾、舊軍用槌與長柄道具。掛牆色降低對比，櫃檯中央預留乾淨區域給主短劍。主折扣牌保留 `-50¢`，小標籤可用數字或筆痕點到即止。主要牌面做成可替換貼圖，固定保留「原價 100、售價 50 銅幣」的演出資訊。
- **雲丘辨識。** 背後遠處露出三至五棟白牆尖頂屋、粉紫雲海及少量彩旗。前景用米黃石路、零星草簇、木箱和小路標。圖中參考的暖色市集感保留在燈光和層次；此處的環境是高地鎮口。
- **角色比例。** 小旅人維持 C01 的辨識特徵，約兩頭身。哥布林以大手、寬肩和帶角骨盔形成親切的剪影，位置讓圓睜眼睛和笑嘴可讀。巨狼體型如戰馬，深靛或灰藍的大面與清楚耳尾最重要。胖黃鳥只需一塊暖黃輪廓，留在與背景對比清楚的帽沿。
- **光線與材質。** 左上金橘晨光掠過櫃檯、路面與狼背，屋簷下用靛青和灰紫作冷影。手繪水粉平塗、大幾何切面、局部蠟筆排線，消光且無黑色外框。主短劍用淺銀藍、珊瑚握柄與兩三點星芒聚焦。
