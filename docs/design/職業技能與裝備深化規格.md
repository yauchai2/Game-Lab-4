## 一、職業與進階執照系統（Weapon-Defined Classes × 8 條專精流派）

本作堅持**「裝備主武器即切換職業」**的無痛自由度，玩家無須重練角色；當主線推進至 Act 2 勸退公會取得「進階補簽執照」後，四大基礎職業各自展開 **2 條截然不同的終局流派專精（共 8 條 Build 路線）**：

| 基礎職業（主武器） | 進階流派 A（進攻／機制特化） | 進階流派 B（戰術／團隊特化） | 核心機制關鍵字 |
| :--- | :--- | :--- | :--- |
| **前線反擊手**<br>（短劍＋圓盾） | **空降飛天騎士**：專精下騎騰空下劈、滯空暴擊倍率與落地重置上鞍 | **鐵壁格擋管家**：精準舉盾彈反 Boss 紅光攻擊，直接疊滿巨量破防值並反彈傷害 | `破防`、`下騎`、`格擋反擊` |
| **弱點狙擊手**<br>（彈弓／輕弓） | **信使神射手**：騎乘移動射擊不減速，命中弱點自動觸發胖黃鳥「紅章連蓋」 | **果實散射獵人**：裝填黏性漿果與分裂石子，大範圍掛上緩速、流血與易傷 | `弱點`、`蓋章`、`騎射` |
| **戰術爆破手**<br>（舊軍扳手＋機關包） | **廢品拆彈專家**：佈置定時炸藥與誘餌木樁，靠巨獸撞飛敵人進雷區引爆連鎖爆炸 | **發條傀儡技師**：回收戰場廢鐵，召喚 2–3 台會自動幫忙敲人的退休發條小兵 | `陷阱`、`連鎖引爆`、`召喚` |
| **旅途支援師**<br>（營火提燈＋湯勺法杖） | **營火野炊大廚**：隨身丟出「移動營火」，領域內持續灼燒敵人並讓隊友獲得烤魚增傷 | **勸退公會牧師**：以暖光提燈為全隊與巨獸套上護盾，並在多人副本共享水壺回復效果 | `營火`、`灼燒`、`團隊護盾` |

## 二、技能系統架構（6 鍵輕量操作 × PoE 2 式輔助印章串聯）

### 1. 戰鬥 6 鍵位配置（手把與鍵鼠皆順手）
1. **左鍵 / `J`（基礎連擊）**：依主武器決定的 3 段普攻或移動射擊，回復基礎資源。
2. **右鍵 / `K`（核心流派技）**：流派主要輸出或控場技能（可鑲嵌最多 4 顆改裝輔助印章）。
3. **`Space`（閃避翻滾／衝刺）**：短暫無敵幀，翻滾穿過敵人可觸發部分鞋靴或鞍座詞綴。
4. **`F`（無縫上下騎／鞍座特技）**：騎乘與步行切換；裝備傳奇鞍座時觸發專屬動作（如彈簧彈飛下劈）。
5. **`Q`（巨獸協作破防技）**：指揮退休巨獸發動肩撞、舉盾、踏風或翻滾，專打 Boss 紅光蓄力與破防。
6. **`1`（隨身水壺）＋ `C`（胖黃鳥求救／蓋章指令）**：喝下營火料理水壺觸發限時增益；副本內按 `C` 召喚隊友助拳或指揮黃鳥蓋章。

| **前線反擊手** | 三段輕快短劍斬（第三段微位移） | **破甲重劈**：蓄力半秒劈出月牙波，對踉蹌目標傷害 +80% | **圓盾拍擊**：舉盾 0.5 秒完美格擋時震飛周圍小怪並觸發滿額暴擊 |
| **弱點狙擊手** | 邊走邊射彈弓石子（支援騎乘射擊） | **貫穿信標箭**：射出帶紅繩的信標，命中後胖黃鳥俯衝補蓋 1 次紅章 | **後躍散射**：向後翻躍並朝扇形灑出 5 顆麻痺漿果 |

| 輔助印章名稱 | 標籤需求 | 串聯效果（改變手感與流派） |

## 三、裝備系統深化（9 格雙軌裝備 × 前後綴詞綴庫 × 造裝通貨）

### 1. 裝備稀有度與詞綴上限（對標 PoE 2）
- **普通白裝（Normal）**：0 詞綴，但擁有最高品質底材潛力，適合餵給回收史萊姆波波換通貨，或直接拿來當造裝胚子。
- **魔法藍裝（Magic）**：最多 **2 條詞綴（1 前綴＋1 後綴）**，前期過渡主力。
- **稀有黃裝（Rare）**：最多 **6 條詞綴（3 前綴＋3 後綴）**，終局數值天花板，可透過造裝通貨反覆洗鍊。
- **傳奇橘裝（Unique）**：擁有**無法被洗出、直接改寫玩法的專屬核心特效**，是構築流派的靈魂。

### 2. 前綴（Prefix）與後綴（Suffix）完整詞綴池

| 分類 | 詞綴方向 | 詞綴範例（T3 前期 → T1 終局階級） |
| :--- | :--- | :--- |
| **前綴（Prefix）**<br>主掌基礎輸出與生存 | 物理／元素基礎傷害 | 鋒利（`+1` → `+8` 基礎攻擊）、烈焰烤爐（附加火傷並觸發灼燒） |
| | 破防與韌性削減 | 沉重敲擊（對 Boss 韌性條削減 `+15%` → `+45%`） |
| | 生命與護盾基底 | 溫暖厚絨（旅人最大生命 `+1` → `+4` 心）、巨獸鐵皮（巨獸減傷 `+8%` → `+24%`） |
| **後綴（Suffix）**<br>主掌暴擊、節奏與聯動 | 暴擊與攻速 | 會心（暴擊率 `+10%` → `+35%`）、疾手（攻速／施法速度 `+8%` → `+25%`） |
| | 流派觸發增傷 | 破甲（對踉蹌目標傷害 `+20%` → `+65%`）、空降（下騎 3 秒內暴傷 `+30%` → `+90%`） |
| | 移動與掉寶功能 | 輕盈（移速 `+8%` → `+20%`）、四葉草（裝備稀有度掉落 `+15%` → `+50%`）、冷卻縮短 |

## 四、三套經典終局配裝範例（Endgame Build Recipes）

1. **「彈射飛天斬」爆發流（單刷／速刷王首選）**
   - **配置**：`前線反擊手（空降飛天騎士）` ＋ `退休斥候巨狼` ＋ 傳奇《彈簧試驗鞍座》
   - **技能串聯**：核心技【破甲重劈】串聯《破防必爆印章》＋《下騎蓄能印章》＋《巨獸共鳴印章》
   - **輸出循環**：騎狼 `Q` 肩撞破防 → `F` 彈簧飛天 200% 暴擊下劈 → 落地接必爆【破甲重劈】秒殺精英 → 翻滾上鞍繼續衝刺。
2. **「百倍蓋章暴富」騎射流（公共刷怪區打寶首選）**
   - **配置**：`弱點狙擊手（信使神射手）` ＋ `退休雲海巨鹿` ＋ 傳奇《郵政局長金羽帽》
   - **技能串聯**：核心技【貫穿信標箭】串聯《多重彈射印章》＋《連鎖蓋章印章》
   - **輸出循環**：開雲海巨鹿 `Q` 踏風加速 → 全程騎在鹿背上繞圈散射，滿螢幕胖黃鳥金色殘影連蓋紅章，一邊清怪一邊狂噴通貨碎片。
3. **「移動拉麵鍋坦奶」組隊流（4 人副本助拳神角）**
   - **配置**：`旅途支援師（營火野炊大廚）` ＋ `退休重甲巨熊` ＋ 傳奇《巨熊的鑄鐵拉麵鍋》＋《過勞哨長的舊草帽》
   - **技能串聯**：核心技【隨身小營火】串聯《熱茶分享印章》＋《營火餘燼印章》
   - **輸出循環**：巨熊 `Q` 舉盾嘲諷聚怪並掉出迷你茶攤 → 旅人放下沸騰拉麵大鍋同時燙傷怪物＋替全隊回血加攻速，拉新手打劇情副本穩如泰山。
