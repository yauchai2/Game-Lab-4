# 西岸港城｜GPT Image 多視圖出圖紀錄

這批補齊 11 件資產，共 35 張獨立 Tripo3D 多視圖 PNG。B03–B08、S04、C02、C03 為正面、左側、背面三張。S03、S05 另附右側。C01 沿用使用者已有的模型。

## 圖源與整理

- 每件使用 GPT Image 生成同一件物件的正交式原稿。Blender 幾何投影作為造型和視角參考。供上傳的 PNG 取自 GPT Image 原稿。B04 與 B07 另生一版以保留敞開入口，S05 另生一版以清楚標出左舷登船缺口。
- [GPT Image 原稿](GPT-Image原稿/) 保留完整像素及四格構圖。[獨立送件圖](GPT-Image送件/) 按資產 ID 分組。上傳時選該 ID 的獨立圖片，依檔名指定方向。
- 原稿為 1254 × 1254 px，每格約 627 × 627 px。拆格後按同組可見主體校正接地線與顯示高度，再重採樣到 1536 × 1536 px。重採樣保持構圖與像素格式，原生細節以原稿解析度為準。[圖檔清單及 SHA-256](GPT-Image圖檔清單.csv)
