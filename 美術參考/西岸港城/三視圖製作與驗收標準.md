# 西岸港城｜Tripo3D 三視圖製作與驗收標準

本文件補充[首場景資產與組裝計畫](資產與組裝計畫.md)。使用港城概念圖決定外形、材質及場景氣質，使用同一份可量測的低模或正交基準鎖定各面幾何。以下尺寸、留白和容差都是本專案的起始製作標準。最終以 Tripo 回傳模型的幾何及 Godot 實測驗收。

## 2. 相機、尺寸與影像

- 所有水平視圖用**正交相機、俯仰 0°、翻滾 0°**，以共同原點轉向。固定正交尺寸、解析度和相機高度。視圖必須呈現正交投影的邊線與遮擋。
- 同件採相同尺寸的方形 RGB PNG、sRGB。以 **1536 × 1536 px 或 2048 × 2048 px** 製作，實際送件前核對使用中的 Tripo 入口限制。若需降採樣，整組使用同一倍率。
- 整組使用同一個 px／m 比例。以**所有送件視圖中的最大投影邊長**佔畫布約 **75–85%** 構圖，每邊至少約 5% 留白。狹長物的端視圖可能自然較小。整組鎖定世界原點在畫布的位置，水平視圖共用接地基線。懸掛道具、船隻等另記掛點、水線或龍骨作為定位資料。
- 用純色淺中灰底，建議從 `#DADADA` 起試。背景需與所有輪廓及孔洞有足夠明度差，淺色物件可整組改用較深中灰。各面維持相同底色與中性、柔和照明。保留啞面大色塊、局部乾刷、材質轉折；陰影、濕亮反射、燈光、火光和環境反光留給場景。
- 同一物件各面固定瓦色、木色、金屬位置、形狀磨損及圖案歸屬。背面露出與正面不同的結構時，按同一外殼延伸。真正的孔洞需讀得出孔口及厚度，能看穿之處露出背景。深凹部應保留可辨認的底面或內側面。

## 3. 先鎖定結構，再用 GPT Image 生成

**正式交付的多視圖 PNG 由 GPT Image 生成。** 先固定正面設計，再提供同一造型參考與各面幾何約束生成側面、背面和必要的補面。Blender 或 Godot 的正交渲染只用作輸入底稿與人工幾何核對。交接時逐件記錄出圖來源及驗收狀態，三視圖需比對共同基線、比例、開口及構造位置，未通過就保留待修狀態。

1. **建立資產卡。** 記錄 ID、用途、米制寬×高×深、正面方向、原點、底面、關鍵尺寸、裝配點、可動件、通孔、凹槽及材質分區。港圖未交代的背面和內部先依用途定稿。通行尺寸要以玩家及獸伴的實際碰撞體決定。
2. **做同源正交底稿。** 建築、船骨、吊車等先用 Blender 或 Godot 做簡模，輸出輪廓、深度關係及各面投影。木桶、陶罐等簡單物件可用同尺度的正交輪廓稿。角色先鎖共同姿勢、骨架比例與可動關節位置。人形依預定綁定流程選擇中性姿勢，四足保持腳掌落地、四肢可分、尾巴與身體分開。
3. **用 GPT Image 定稿正面材質，再用同一設計生成各面。** 後續視角同時依據已定稿的正面樣式及當面的正交底稿，逐面核對。窗、船肋和大型枝葉先確認數量與位置，再做乾筆和邊緣磨損。
4. **把必須精準的機能留給可編輯的幾何。** 有尺寸要求的門框、通行地面、吊點、薄木肋及動畫件，用低模定義接頭與空間。Tripo 出現封口或融合時，按低模修整或替換局部。碰撞、門扇鉸鏈、角色導航、旗布、吊索及發光面獨立匯入或搭建。

## 4. 送件前的量測與退件

令 D 為整組水平視圖之中最大的投影邊長，以像素計算。若 D = 1200 px，1% D 就是 12 px。標出 5–10 個影響輪廓、通行或裝配的基準，如屋脊端點、簷高、門檻、門洞頂、船肋中心和樹冠枝節。對比各自的正交底稿，前後視圖比較時把座標映射回同一物件軸。

| 檢查項目 | 通過條件 |
| --- | --- |
| 基準線 | 同一投影基準線對齊，接地線的畫面偏差 ≤ 2 px。 |
| 關鍵點 | 可見結構點與該面底稿偏差 ≤ 1% D。屋脊、門檻、窗台、裝配面等同一個世界高度，在各可見水平視圖也須對齊。 |
| 輪廓尺寸 | 各視圖指定的主要投影寬、高或深度與底稿差 ≤ 2% D。非對稱及遮擋由底稿定義。 |
| 數量與連接 | 窗、梁、船肋和主葉束的數量、側別、連接順序與資產卡一致。承重關係、門洞側壁和有意透空全部可解讀。 |
| 小型結構 | 關鍵薄件或空隙在實際送件尺寸下能清楚讀出。若寬度只剩幾個像素，依重要性增加取景尺寸、拆件，或用可編輯幾何保留該處。 |
| 退件條件 | 重畫造成不同屋頂坡度、側面窗位漂移、鏡像錯側、梁柱增減、通孔畫成實面、角色變姿勢，或單張構圖被獨立縮放。結構問題回到底稿校正。 |

## 5. 回傳 GLB 的驗收

1. **比對六個方向。** 米制縮放、對齊軸向與原點後，從正面、兩側、背面、頂視及遊戲斜俯角檢查。主要外形的寬、高、深與資產卡目標差建議各在 ±3% 以內。門洞、裝配面與玩法要求依資產卡的獨立尺寸驗收。
2. **檢查玩法及透空。** 旅人與獸伴可穿過 B03 門洞。S04 船肋之間仍能從側面和斜俯角看到背景，船內空間可讀。N01 的樹葉保持可辨識的分束，從遊戲鏡頭看有透空輪廓。
3. **檢查網格與材質。** 看破面、相交或意外黏合、翻面、UV 拉伸、接縫跳色、材質烘入陰影等問題。回到 Godot 以港城主光和遊戲距離預覽。可編輯接點或玩法開口失敗時，先修正該處再進場組裝。
