# 《借影之森》西岸港城｜首場景關卡與 NPC 計畫

[關卡配置圖 PNG](west-harbor-gameplay-plan.png) · [可編輯 SVG](west-harbor-gameplay-plan.svg) · [平面配置與組裝定位](平面配置與組裝定位.md)

西岸港城在本方案中是**橙瓦埠的港區**。玩家第一次由海路抵達，經燈籠食堂進青眠林。遇見烏麥後，玩家帶牠回同一座城，重新經過曾走過的石路，在獸醫與陶芮面前發現人工削影的痕跡。港區保留市集、船塢與燈塔等散步空間，主線只需記住藍旗、暖燈籠、林口與鐵匠爐。

貨船抵達屬新增的可玩序幕。食堂領乾糧、栗粒在林中揭露離體影子、林中首次遇見烏麥、獸醫認出切痕、陶芮辨認削影刀，沿用現有故事。林中首次遇見烏麥的演出為正式主線的開場事件。常駐幼狼依首輪遠征企劃於野外營火加入；烏麥是劇情狼，兩者有獨立身份與進度。陶芮首次碰面可以先談小尺寸裝備，削影刀的資訊保留到返城。綺砂、劇場牧戶與岩角獸各留在原劇情的後續場域。

## 主線體驗與回訪

| 階段 | 玩家走到哪裡、做甚麼 | 可跳過、回訪與提示 |
| --- | --- | --- |
| 初到港區 | S05 貨船甲板 → G1 跳板 → B03 藍旗報到處 → T1 石拱路。報到員一句說明食堂方向。 | 報到可略過。由藍旗旁的指示牌與遠處燈籠引路。可先逛市集、造船場、工坊與燈塔。 |
| 食堂出發 | 由市集經 T5 或東側 R1 上露台。進 B04 找掌櫃領取乾糧，長桌可看遠征告示。從食堂東側上林徑，到 F1 明確確認後前往青眠林。 | 走到林口尚未領乾糧時，出發牌提示回食堂。單人可直接出發，同行邀請隨連線里程碑加入。 |
| 野外旅程 | 現有故事包含避雨、初遇烏麥、栗粒示警、岩角獸與斷崖。返城入口掛在野外遠征完成點。 | 林中完成條件由遠征端傳回。港區使用轉場點與返程錨點，灰盒可用開發測試狀態覆核兩端。 |
| 帶狼返城 | 從林口回到 F2，沿 R1 回食堂東側，由獸醫在露台驗傷。再沿主街到 B07 找陶芮辨認刀痕。 | 可先繞去鐵匠棚，陶芮會指向獸醫。對話結束後，獸醫線索保存在旅程，重新進城可繼續。 |
| 長桌記錄 | 回 B04 將本次實際取得的觀察記入長桌及旅行簿，收束港區首章。 | 走溪路或借影路都能交回自己的觀察，一份可交。共享合成留給連線階段，日後重複交談保留回顧。 |

港區只在 **F1 出發資格與返城診斷順序**設劇情門檻。市集、造船場、工坊、燈塔各有回程路，適合先逛再回主線。以初到港區至離城約 3–5 分鐘為試玩目標，另行記錄自願探索時間。

- **灰盒與存檔。** 在既有規劃的 `WestHarbor.tscn` 下建立入口、返程、互動及安全 `Marker3D`，用 `Area3D` 做轉場與跌落回復。旅程依序記錄已領乾糧、已帶烏麥返城、已驗傷、已辨刀與已交回觀察。重複互動只給對應階段的對白，發放與結算各執行一次。首次登岸和返城的出生點由進入來源決定。
- **演出與導航。** B03、B04、B07 只做需要的前廳、用餐廳與棚口，保留 Tripo3D 外殼、分件屋頂與步行碰撞。NPC 在對話時原地轉身，避免長路巡邏和路口堆疊。窄棚口及食堂桌前測一次玩家單獨通行、一次帶兩隻劇情／常駐獸的返城演出；可讓幼狼在寬處等待並於離開時跟上。
- **增補資產。** 沿用 C01 旅人、C02 狼母件與 C03 港民母件。陶芮、栗粒需要可辨識的專屬輪廓，先以替身驗證身高、頭部和互動距離，再出三視圖。幼狼和烏麥可共用合適的狼骨架，依體型、左耳與色塊辨識；站位牌、報到矮檯、診療墊、藥箱、長桌與矮櫃可用現有道具或簡模。
- **驗收順序。** 先用替身走完「船 → 食堂 → F1」，驗證略過報到仍能出發、領糧前林口有明確提示。用返城測試狀態重走「F2 → 獸醫 → 陶芮 → 長桌」，測試先找陶芮、重複交付、由兩條野外路線各帶一份觀察回來；再巡住宅巷、造船場雙梯、燈塔平台及封閉門。最後用遊戲鏡頭檢查 B03／B04 屋頂淡出前後的入口辨識、R1 回城轉折與角色避讓。本案目前為設計規格，動線與室內碰撞待灰盒驗證。
