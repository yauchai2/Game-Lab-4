# 西岸港城｜Tripo GLB 第一批回傳

本批為創作總監提供的 20 件 Tripo3D 輸出。依原始單張送件圖和模型預覽辨認資產 ID，存檔時保留 GLB 內容，並以 ID 命名。原匯出檔名、檔案大小及 SHA-256 見[回傳清冊](manifest.csv)。

已逐件核對 GLB 2.0 容器、網格與內嵌圖像，並用 Godot 4.6.3 的 `GLTFDocument` 成功讀入及建立場景。每件均含一個網格、一份材質及一張內嵌圖像。模型以斜俯預覽核對用途。正式比例、朝向、接地點、碰撞與遊戲光照表現待組裝時確認。
