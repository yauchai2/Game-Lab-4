# 西岸港城｜水粉植栽、Billboard 與全域風場

本案把影片的草卡、葉卡和全域風場用於《借影之森》的港城植栽。保留手繪感與大塊幾何剪影，使用暖日光、藍紫調暗部和少量乾刷。先在一小段石牆坡腳試做草叢與葉團樹冠，把實際遊戲鏡頭下看到的差異帶回資產評估。N01 棕櫚先沿用立體樹幹與大塊葉束，驗證需要風動時再加葉束局部彎曲。近景大葉植栽也可沿用立體母件。

## Godot 4.6 的實作要點

- **區分顯示位置、受光位置與投影模型。** `VERTEX` 負責葉卡展開及風吹。修改 `LIGHT_VERTEX` 可提供另一個光照採樣位置，畫面上的幾何仍由 `VERTEX` 決定。樹葉的受光代理用**展開及風吹前的樹冠頂點**，以原始模型到視圖的矩陣轉換後再寫入 `LIGHT_VERTEX`。另保留原樹冠的朝外法線做大色階，避免葉卡轉向相機時，整棵樹的亮面跟著轉。靜態陰影代理另行處理投射。 [Godot 空間著色器](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/spatial_shader.html) · [GeometryInstance3D](https://docs.godotengine.org/en/4.6/classes/class_geometryinstance3d.html)
- **渲染器須做對照。** 目前專案使用 GL Compatibility。Godot 4.6.3 的 GLES3 程式在頂點階段生成陰影座標，片元階段改寫 `LIGHT_VERTEX` 不會重算這組座標。影片的「整株同一點接收陰影」先在獨立測試場景用 Forward+ 對照。Compatibility 先驗證上向法線、程序風場、靜態投影代理，再用陰影跨株測試檢查結果。若目標須留在 Compatibility，而跨株切割仍明顯，可試用每株共用的預烘明暗值或區域色調，並記錄失去即時受影一致性的取捨。 [Godot 4.6.3 GLES3 來源](https://github.com/godotengine/godot/blob/4.6.3-stable/drivers/gles3/shaders/scene.glsl) · [Godot 問題 #101119](https://github.com/godotengine/godot/issues/101119)
- **啞面、水粉色階。** 以 `specular_disabled` 關閉直射高光，材質粗糙度起點設 `ROUGHNESS = 1.0`，`METALLIC = 0.0`，再檢查環境反射。`ROUGHNESS = 0.0` 代表光滑面。港城以遊戲鏡頭下不出現塑膠高光為驗收依據。草與地表共用底色範圍、光階與環境光設定，取地表實測色調做校正。斜坡和地面材質交界也納入比對。光階可從 3 級試起，用 `ceil(clamp(NdotL, 0.0, 1.0) * steps) / steps` 並將步數下限設為 1，再加入光色和衰減。樹冠只在受光側試少量低對比邊光，維持無黑框的設計。 [影片 04:18](https://www.youtube.com/watch?v=iPbYzFWECz4&t=258) · [Godot 空間著色器](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/spatial_shader.html)
- **遮罩和邊緣。** 用遮罩的灰階通道輸出 `ALPHA`，以 `ALPHA_SCISSOR_THRESHOLD` 做剪裁。初值可試 0.5。檢查 mipmaps、濾波與可用的抗鋸齒模式。若遠距葉緣閃動，先加粗葉尖和草梢、合併接近像素大小的小洞，再比較遮罩閾值與 mip 層。乾刷顆粒主要留在底色貼圖內，外輪廓用少量能在遊戲距離讀到的缺口。 [Godot 材質與 Alpha 裁切](https://docs.godotengine.org/en/4.6/tutorials/3d/standard_material_3d.html)
- **相機方向與地形。** 正交相機使用固定水平朝向建 Y Billboard，保留實例縮放。風吹沿 billboard 本地 X，草的根頂權重在匯入後確認。僅當 UV 根部為 1、梢端為 0 時使用 `1.0 - UV.y`。平地以世界上向法線受光，港城坡地若光階有明顯斷層，可在撒佈時保留落點地表法線供 shader 比對，草卡仍保持直立。
- **邊界與成本。** 把最大風動及葉卡展開量算進網格或分區 MultiMesh 的 `custom_aabb`。分區較容易裁切視野外的植栽。用港城相機下實際的覆蓋率測 GPU 成本與透明裁切的疊畫。主通道、台階邊、門洞與站位保持清楚。 [Godot MultiMesh](https://docs.godotengine.org/en/4.6/tutorials/performance/using_multimesh.html) · [ArrayMesh 邊界](https://docs.godotengine.org/en/4.6/classes/class_arraymesh.html)

## 共用風場約定

以下只作首輪可調參數。全域變數先在測試專案的 Shader Globals 定義，再載入 `Grass.gdshader` 和 `TreeLeaves.gdshader`。

| 變數 | 格式 | 定義 |
| --- | --- | --- |
| `wind_noise` | `sampler2D` | 以 `FastNoiseLite` 建立的無縫 `NoiseTexture2D`，取樣啟用 repeat。 |
| `wind_direction` | `vec2` | 世界 XZ 的標準化方向。輸入零向量時關閉方向性滾動，避免對零向量取 normalize。 |
| `wind_scale` | `float` | 世界公尺換算成雜訊 UV 的倍率。值越大，空間變化越密。 |
| `wind_speed` | `float` | 噪聲圖案在世界平面上的推進速度，單位 m/s。 |
| `wind_strength` | `float` | 全域強度倍率。草材質另有最大位移，葉材質另有最大旋轉角。 |

取樣基準可從 `(anchor_xz - direction * TIME * wind_speed) * wind_scale` 起步。用共享參數維持風團連續，再讓各材質調整幅度。同一張草卡以同一根部採樣，搭配根頂權重做形變。每張葉卡的微轉以同一葉卡中心採樣。最先用靜止鏡頭檢查風團是沿地表掠過、草梢擺動、樹幹和陰影代理保持穩定。 [Godot Shader Globals](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/shading_language.html) · [NoiseTexture2D](https://docs.godotengine.org/en/4.6/classes/class_noisetexture2d.html)

## 交給 AI 的試作工作

1. **圖片生成。** 生成疏草、矮草和寬葉團各一個剪影，底部接地。每種交一張純黑底、純白主體的灰階遮罩，以及同構圖的消光水粉底色稿。底色用少量大色塊、乾刷筆觸及青綠相近色，避免落地陰影與鏡面亮點。寬葉保持厚實，避免尖碎草絲在斜俯鏡頭下高頻跳動。
2. **網格與資源。** 讓 AI 寫 Blender 4.x 腳本，輸出有根部樞紐的草卡 GLB、一株測試樹冠及可獨立掛接的靜態投影代理。對草卡確認面角法線、UV 根部、落地基準和實際尺寸。對樹冠確認每面 UV、葉卡中心、四角次序及代理輪廓。 [Blender Data Transfer](https://docs.blender.org/manual/en/4.5/modeling/modifiers/modify/data_transfer.html)
3. **Godot 測試場景。** 以同一斜俯正交相機、同一盞方向光和同一石牆遮擋，並排放無風／有風、原位置／代理位置接收陰影、葉卡投影／靜態代理投影。先在現有 Compatibility 對照，再以 Forward+ 重跑。以相同鏡頭速度錄下往返過程，附 Godot 版本、渲染器、GPU、畫面規格與各選項的截圖或短片。
4. **驗收後佈植。** 草根不滑移，斜坡草地接色可讀；用兩株分處陰影兩側驗證實例採樣點；中央與畫面邊緣的草木不得突然消失；來回移動相機時，樹影不得跟著葉卡抖動。再以港城平面圖選食堂露台外、住宅巷牆腳和燈塔坡腳小面積佈植，避免主路和互動區的植物遮擋。

目前為技術規格，尚未建立 Shader、測試場景或完成效能與畫面驗收。
