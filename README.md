# 《補簽遠行》（暫名） · Game Lab 4

一款偏向 MMORPG 結構的童話奇幻動作 RPG。故事設定於「百年大戰早已結束、魔物全都退休轉行做生意」的和平世界——唯獨荒野深處的舊時代 Boss 至今仍未收到停戰通知。玩家將扮演極少說話、以動作與表情互動的小旅人，騎乘冷靜可靠的巨型動物夥伴、帶著路癡胖黃羽信使鳥，透過體型差開路、合擊破防與雙軌刷裝，幫老古董 Boss 們辦理「強制退休」。

## 最新核心規格（唯一企劃基準）

所有新開發、美術與劇情實作均以 `docs/` 內三份定案規格為準：

1. [故事與世界觀企劃-補簽遠行](docs/故事與世界觀企劃-補簽遠行.md)：完整世界觀、鐵三角角色、五大地貌 Boss 與 Phase 0–6 全流程。
2. [核心玩法與雙軌配裝企劃](docs/核心玩法與雙軌配裝企劃.md)：核心玩法循環、武器定職業、退休巨獸夥伴、旅人 × 巨獸雙軌裝備與 Build 系統。
3. [序章黃金五分鐘分鏡與實作規格](docs/序章黃金五分鐘分鏡與實作規格.md)：沉默主角表達規範、A–D 區無縫場景動線、完整分鏡對白與 Godot 4 實作清單。

## 本機試玩（現行技術驗證灰盒）

用 **Godot 4.6.3** 開啟 [game/project.godot](game/project.godot)，按 **F5**。目前公開版先啟動既有灰盒場景 [game/harbor/Harbor.tscn](game/harbor/Harbor.tscn)，供驗證騎乘、下騎穿窄門開閘與人獸合擊破防的基礎操作；後續序章將依最新 [序章黃金五分鐘分鏡與實作規格](docs/序章黃金五分鐘分鏡與實作規格.md) 實作。

| 按鍵 | 灰盒操作 |
| --- | --- |
| WASD 或方向鍵 | 移動 |
| E / F | 互動 / 上下騎 |
| Q / 滑鼠左鍵 | 指揮獸伴破防頂住 / 攻擊 |
| 空白鍵 / R | 裝備盾後舉盾 / 重新開始 |
