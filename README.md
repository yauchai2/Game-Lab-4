# 《借影之森》

一款以獸伴、借影與共同遠征為核心的手繪 MMORPG。遊戲的四個重點是 **簡約、氛圍、手繪感、人味**。

從[開工決策與首輪試作](開工決策與首輪試作.md)開始。世界設定見[核心企劃](借影之森-MMORPG核心企劃.md)，里程碑與預算見[獨立開發製作企劃](借影之森-獨立開發製作企劃.md)。

## 本機試玩

在 GitHub Desktop 選取交付版本所在的分支，按 **Fetch origin** 檢查更新，有遠端更新時按 **Pull origin** 拉取。首次使用 Godot 時，從專案管理器匯入同一個本機儲存庫內的 [game/project.godot](game/project.godot)。後續更新可開啟已匯入的專案，按 **F5** 試玩。目前灰盒以 Godot 4.6.3 驗證。

最新的[立體微縮場景方向](借影之森-鏡頭與核心玩法.md#立體微縮場景方向)記錄斷崖灰盒的新鏡頭與美術試驗。
