# 《邊境遠征》 · Game Lab 4

一款以大型獸伴、狩獵、裝備與遠征為核心的童話奇幻 RPG。旅人可以騎乘獸伴，在戰鬥中互相掩護，也會遇上需要兩種體型才能通過的地形。

## Godot 專案

可以用 Godot 4.6.3 開啟 [game/project.godot](game/project.godot)。舊港城與斷崖原型已移除，目前沒有可執行的主場景。
