| 分類 | 資產數 | 送件 PNG | 驗收 PNG |

在各分類下開啟以資產 ID 和名稱命名的資料夾，選取同一 ID 的 PNG 送到 Tripo3D。三視圖用 front（正面）、left（物件左側）、back（背面）。CH-B04 四視圖另有 right（物件右側）。單圖用 oblique（斜角）。

個別資產資料夾內的「驗收補圖」包含頂面、底面和開蓋視角。檔名含 qa_ 的圖片供驗收。

所有 PNG 源自 GPT Image。檔案以 1536 × 1536 交付，多數原稿裁格為 627 × 627。清冊列出每張圖片的裁格尺寸、原稿連結與校驗值。
